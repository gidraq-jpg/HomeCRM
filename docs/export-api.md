# Экспорт данных (DATA-2)

Решения по составу, доступу, корзине и формату — [ADR-0030](adr/0030-data-export.md).

## Скачать ZIP

`POST /api/export/archive`, cookie вошедшего участника и свой Origin:

```json
{ "scope": { "kind": "personal" }, "password": "<повторный ввод>", "confirmed": true }
```

Администратор выбранного дома использует `scope: { "kind": "household", "householdId": "<UUID дома>" }`. Личная область всегда принадлежит сессии; чужой `ownerId` не принимается. Пароль не сохраняется на клиенте и не попадает в журнал. Второй фактор администратора должен быть включён.

Успех — `200 application/zip`, `Content-Disposition: attachment; filename="homecrm-personal.zip"` или `homecrm-household.zip`, `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, размер в `Content-Length`. Внутри `manifest.json`, JSON-массивы по видам, папка `files/`. Строки сохраняют UUID и связи, корзину, календарные даты и моменты времени; пути файлов указаны в `archive_path`. Состав и схемы версии 1 — `packages/shared/src/export.ts`.

Ошибки: 400 `INVALID_INPUT` (включая отсутствие подтверждения), 401 без сессии, 403 `ACCESS_DENIED`/`SECOND_FACTOR_REQUIRED`/`INVALID_PASSWORD`, 429 с `Retry-After` при лимите запросов или блокировке подбора пароля, 500 `EXPORT_FAILED` при ошибке сборки/файла/журнала. Неполный архив не выдаётся. При отказе можно повторить запрос с новым вводом пароля; каждый успешно подготовленный архив получает отдельную отметку.

## История

`GET /api/export/history` — последние 50 видимых отметок, от новых к старым. Личные видит только автор, общие — действующие администраторы соответствующего дома. Контракт `ExportHistoryItem`: `id`, `account_id`, `kind`, `household_id` (null для личного), `created_at`, `counts`, `size_bytes`, `actor_name` (семейное имя для общего, null для личного). Временная отметка означает подготовку архива к передаче; сохранение файла на устройство сервер не подтверждает.

Старый `POST /api/export` сохранён для совместимости прежних JSON-клиентов. Новый экран использует только ZIP-маршрут.

## Проверка

Тесты используют вымышленную семью и отдельные PostgreSQL. Проверяются точные наборы личных и общих записей, корзина, историческая приватность событий, скрытые контакты, SHA-256 оригиналов, RLS журнала, отсутствие секретов, лимиты/блокировки/отзыв сессии и удаление временного ZIP после ошибки. Масштабный сценарий — 1000 заметок и 50 файлов: запись архива начинается до чтения всех файлов, одновременных чтений не больше одного.
