# UI-1 — целевая проверка Studio

14 октября 2026, Linux Playwright 1.63.0 / Chromium в отдельном compose `homecrm-test-ui-1-studio`, вымышленная тестовая семья. Рабочее окружение не использовалось.

- `pnpm test:changed`: 2 файла, 20/20 тестов.
- Отдельная сборка прототипа 0.5: 4/4 Linux smoke на 360/412, открытие из подпапки и отсутствие внешних запросов; её прежняя система не включает Studio.
- Типы клиента и e2e: пройдены после полной установки зависимостей worktree.
- Целевой Linux Playwright: 13/13. Существующие shell (пять разделов, фильтр и его сохранение, «+», поиск и неизвестный адрес), вход ребёнка, один desktop smoke; дополнительная временная проверка профиля, локальных шрифтов, скрытия dock при изменении viewport и текста 200%.
- Axe: серьёзных и критичных замечаний нет; цели от 44 px, без горизонтальной прокрутки на 360/412 и при 200%.
- Roboto 300/400/500 с кириллицей и латиницей загружается локально; сетевые запросы проверки — только к собственному тестовому серверу. В сборке шесть WOFF2, включённых в PWA precache.
- Первый прогон выявил узкую вкладку «План» и недостаточный контраст текста на тёплом фоне; исправлены общими токенами и CSS, без изменения assertions/тайм-аутов.
- Снимки общей оболочки: [360](studio-w360.png), [412](studio-w412.png), [desktop](studio-desktop.png), [лист действий](studio-sheet-360.png), [вход](studio-login-412.png), текст 200%: [360](studio-w360-text200.png), [412](studio-w412-text200.png).
- Приветствие, показатели и композиция «Сегодня» — UI-2; экраны входа и специальные стили модулей — UI-3. Снимок входа в UI-1 проверяет отсутствие регрессии общей системы, его окончательный логотип переносит UI-3.
- Физические телефоны, настоящая экранная клавиатура, выпуск и независимое ревью — последующие шаги. Изменение viewport проверяет существующий механизм скрытия, а не нативную клавиатуру Android.

Источник утверждённого растра: точная копия `prototypes/voice-homecrm/qa/variant-1-393.png`; PNG-иконки PWA — Chromium-экспорт `apps/web/public/icon.svg` с точной геометрией Radix HomeIcon. Снимки выше получены из рабочего клиента, не из прототипа. Автоматический detector impeccable не запускался: локальный движок отсутствует; проверка проводится существующими Playwright/axe и единственным ревьюером проекта.
