# API заметок (R0.4a)

Все маршруты требуют действующую сессию; администратор — с настроенным TOTP. Изменения требуют Origin приложения (или Referer того же происхождения). Тело — JSON; неизвестные поля отвергаются. Ошибки возвращают `{ "code": "…" }`, без текста заметки или запроса базы.

| Маршрут | Действие и тело |
|---|---|
| `GET /api/notes` | Массив кратких записей. Параметры: `scope=all\|personal\|household`, `spaceId`, `trash=true\|false`, `limit=1…100` (50), `offset=0…50000` (0). Закреплённые сначала, затем по времени изменения. RLS фильтрует до пагинации |
| `GET /api/notes/:id` | Карточка: краткие поля, Markdown `body`, `checklist` |
| `POST /api/notes` | Создать: `title`; опционально `body`, `pinned`, `checklist`, `placement: {spaceId, audience?}`, `object: {type: "task", id}`. Без места — своё личное; в контексте объекта — его место, аудитория не шире объекта. Ответ 201 |
| `PATCH /api/notes/:id` | `title`, `body`, `pinned`, `assigneeId`, `checklist` и опционально `expectedUpdatedAt`. Требуется хотя бы одно поле правки. Автор, место, служебные признаки и дата корзины через правку не меняются |
| `POST /api/notes/:id/share` | `{spaceId, audience?}`: личное → общее, только владелец. Каскад чек-листа — в базе |
| `POST /api/notes/:id/personal` | `{confirmed: true}`: общее → своё личное, только автор без чужого вклада |
| `POST /api/notes/:id/copy` | `{}`: новая личная заметка читателя с новыми id заметки и пунктов, без истории; ответ 201 |
| `POST /api/notes/:id/audience` | `{audience, confirmed?}`: взрослый меняет аудиторию. При сужении обязательно `confirmed: true`; ребёнок-ответственный сначала заменяется взрослым |
| `POST /api/notes/:id/access-preview` | `{action: "personal"}` или `{action: "audience", audience}`. Ответ `{updatedAt, losesAccess: [{accountId, displayName}]}`. Не меняет запись, право действия проверяется |
| `POST /api/notes/:id/trash` | `{}`: корзина, дата базы, 30 дней, дочерние пункты удаляются каскадом |
| `POST /api/notes/:id/restore` | `{}`: восстановить; взрослый — автор общего, администратор — любое общее, владелец — своё личное |

Аудитории: `household`, `adults`. Список не содержит Markdown и служебных признаков. Карточка содержит `id`, `title`, `pinned`, `spaceId`, `spaceKind`, `audience`, `authorId`, `assigneeId`, `createdAt`, `updatedAt`, `deletedAt`, `body` и пункты `checklist: [{id, title, done, position, deletedAt}]`. У живой заметки удалённые пункты не показываются. Даты — UTC ISO 8601.

Чек-лист при создании: `[{title, done?}]`; при правке — полный новый список с `id` у существующих пунктов. Пропущенные пункты идут в корзину; чужой id отвергается, вся правка откатывается. Восстановление пункта и правка разделяются внутри транзакции. Пункты с одинаковым id отвергаются.

400 — неверные входные данные; 401 — нет сессии; 403 — запрет действия/Origin/обязательный TOTP; 404 — неизвестная **или невидимая** запись; 409 — конфликт, устаревшая версия, требование подтверждения или неподходящий ответственный; 500 — безопасная ошибка сервера. Между домами перенос не поддерживается; используйте копию. Поиск, файлы, связи и теги — следующие этапы. Экспорт — существующий `POST /api/export` с повторным паролем; подробнее ADR-0020.
