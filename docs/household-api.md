# API состава дома (R0.9a)

Все маршруты требуют сессию и проверяют Origin для изменяющих запросов. Администратору нужен подтверждённый второй фактор. Чтение состава, профиля и приглашений идёт под `homecrm_app` и RLS.

| Маршрут | Назначение |
|---|---|
| `GET /api/households/:householdId/members` | Состав своего действующего дома, включая бывших участников |
| `GET /api/me/profile` | Собственные семейные поля профиля |
| `PATCH /api/me/profile` | Свои `displayName`, `photoFileId`, `birthDate`, `phone`; поля можно передавать отдельно |
| `PATCH /api/households/:householdId/members/:accountId/role` | Администратор меняет роль: `{ "role": "admin" или "adult" или "child" }` |
| `POST /api/households/:householdId/members/:accountId/exclude` | Администратор исключает другого участника; тело `{}` |
| `POST /api/households/:householdId/leave` | Участник уходит сам; тело `{}` |
| `GET /api/households/:householdId/invitations` | Администратор видит действующие непринятые приглашения без токенов |
| `POST /api/invitations` | Существующий AUTH-2: `{ "householdId": "…", "role": "child" }`; вернуть ссылку приглашения |
| `POST /api/households/:householdId/members/:accountId/password-reset` | AUTH-5: администратор выдаёт ссылку ребёнку из состава; тело `{}` |

Состав возвращается массивом: `accountId`, `displayName`, `role`, `isAdult`, `formerMember`, `leftAt`, `photoFileId`, `birthDate`, `phone`. У бывшего участника сохраняется имя; фото, дата рождения и телефон в этой строке — `null`. Логин, почта и сведения о входе сюда не входят. Семейные поля профиля бывшего участника видит он сам и его действующие семьи, но не бывшая семья. Фото пока только UUID будущего файла, без загрузки; дата рождения — `YYYY-MM-DD` или `null`.

Чужой дом или отсутствующий участник — 404. Запрещённое действие — 403 `ACCESS_DENIED`; взрослому и участнику, который взрослый в другом доме, сброс не выдаётся. Последний администратор не может уйти или понизить себя: 409 `LAST_ADMIN`. Конфликт связей или конкурентного изменения — 409 `CONFLICT`. В частности, ответственный за записи «Взрослые» не может стать ребёнком, пока ответственность в этих записях не передана взрослому. Отсутствие подключения обработчика останавливает уход до изменения членства: 503 `WORKER_UNAVAILABLE`.

После ухода личное и учётная запись сохраняются; общие записи сохраняют автора и показывают его как бывшего участника. Ответственность передаётся администратору обработчиком сразу после фиксации ухода. Сбой этого вызова возвращает 503 `RESPONSIBILITY_PENDING`: уход уже завершён, а периодическая очистка повторит передачу идемпотентно; повтор запроса ухода после уже завершённого членства возвращает 404. Рабочее окружение этим изменением не запускается.

Остальные поля входа остаются в существующем `/api/me`; имя там берётся из своего профиля. Отметка о сбросе выбирается по последнему `completedAt`, закрыть её можно спустя 7 дней. Собственные семейные поля включены в `/api/export`, который по AUTH-7 требует повторного пароля. Отдельного поиска и корзины у профиля нет: его жизненный цикл совпадает с учётной записью.
