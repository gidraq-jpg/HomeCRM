# ADR-0015. Один образ Docker для приложения и обработчика

- **Статус:** принято, 5 октября 2026
- **Связано:** план, T15 и разделы 2.2, 7.4; PRD G7

## Контекст

В LifeOS семь контейнеров и ручной перенос в рабочее окружение (H3). Цель HomeCRM — три сервиса приложения плюс внешний вход и выпуск одной командой (G7).

## Решение

- Один образ на базе Node 24: сервер, обработчик и собранный клиент.
- Две команды запуска: `app` (API и раздача PWA) и `worker` (фоновые задачи).
- Один `deploy/compose.yaml` для компьютера и VPS, различия — профилями и файлами окружения.
- Порты публикуются только на `127.0.0.1`; `restart: unless-stopped`.

## Последствия

- Приложение и обработчик всегда одной версии: нет расхождения схем.
- Выпуск — это смена метки образа, откат — возврат прежней (план, раздел 3.3).

## Отклонённые варианты

- **Отдельные образы** — больше сборок и риск разных версий.
- **Без Docker, службами Windows** — не переносится на VPS без переделки.
