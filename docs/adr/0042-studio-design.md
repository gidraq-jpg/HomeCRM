# ADR-0042. Утверждённая система Studio

- **Статус:** принято, 14 октября 2026; шрифт изменён 15 октября 2026 — Studio 2 (бриф D11, PR #60): Onest 300/400/500 вместо Roboto, остальное в силе.
- **Связано:** PRD UI-1/2/3, SPACE-5/6, TASK-4/5/6; [контракт Studio](../design/studio.md); заменяет визуальное решение Calm Focus из [ADR-0007](0007-client-stack.md), остальной клиентский стек сохраняется.

## Решение

Владелец выбрал «Студию» с крупным персональным приветствием и тремя показателями из «Обзора». Сохраняем утверждённую геометрию Radix HomeIcon в логотипе, угольный верх, тёплую светлую панель, терракотовые действия и локальный Roboto 300/400/500 с кириллицей и латиницей. Источник выбранного варианта хранится в репозитории.

Studio включается атрибутом рабочего entry, чтобы не менять общие стили отдельной сборки прототипа 0.5. Существующие классы и поведение оболочки сохраняются; legacy-токены акцента остаются алиасами, успех и опасность имеют отдельные семантические цвета. Единственная новая зависимость `@fontsource/roboto` нужна для одинакового локального шрифта на Windows/Linux/Android и работы без внешнего CDN.

## Последствия

Общая система UI-1 интегрируется первой. UI-2 меняет только композицию «Сегодня» на текущих данных, UI-3 — другие экраны. Демонстрационные данные и мобильный симулятор не переносятся. Проверяем представители общих компонентов в Linux на 360/412 px с axe, desktop и 200% текст; физические телефоны и выпуск остаются отдельной приёмкой владельца.
