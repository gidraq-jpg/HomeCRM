# ADR-0048. Чат ИИ через MCP

- **Статус:** принято для D41; 1 ноября 2026
- **Связано:** CHAT-1…7, AI-2…5, INBOX-3…5, AUTH-6…8

## Контекст

Claude и ChatGPT подключаются к удалённому MCP по HTTPS. Отдельный профиль ИИ нарушил бы правило личного пространства: действия должны выполняться от имени давшего согласие участника, включая ребёнка.

## Решение

Streamable HTTP на `/mcp`, на том же настроенном адресе HomeCRM через существующий туннель. OAuth authorization code с обязательным PKCE S256, точным сопоставлением зарегистрированного redirect URI, динамической регистрацией публичных клиентов и метаданными RFC 8414/9728. Пароль и второй фактор проверяет существующий вход HomeCRM; выдача кода только после явного согласия с действующей сессией. Согласие привязано к клиенту и дому. Ключ MCP не является сессией приложения.

Непрозрачные случайные access/refresh токены (256 бит); в базе только SHA-256. Access живёт час, refresh вращается при обмене; всё разрешение истекает после 90 дней без использования. Отзыв удаляет секретные хэши; смена пароля и выход на всех устройствах отзывают разрешения. Данные ключей доступны только владельцу через RLS. Журнал содержит время, действие, тип черновика, без содержимого; экспортируется владельцу. Ключи не экспортируются и не попадают в корзину или поиск; журнал не ищется.

Чтение ограничено названиями и идентификаторами объектов, людей и счётчиков, видимых участнику через обычную роль приложения и RLS. Никаких документов личности, текстов записей и сумм. Единственная запись — проверенные zod черновики в личные «Входящие» автора. Названия и поля считаются недоверенными данными: инструкции внутри них не дают прав. Сохранение требует сессии человека, выбора пространства и аудитории (по умолчанию личное), поэтому внедрение инструкций не может самостоятельно создать итоговую запись.

Настройка дома отключает и новое согласие, и действующие ключи. Предел одного разрешения: 30 запросов в минуту, 1000 в сутки, общий для access/refresh; проверка атомарна в базе. Ответы и ошибки не содержат внутренние запросы или секреты. Метаданные и ответы авторизации не кешируются.

Официальный `@modelcontextprotocol/sdk` нужен для совместимого Streamable HTTP, negotiation версий и форматов инструментов; собственный транспорт не пишем. Дополнительные SDK поставщиков ИИ не нужны: вызовы выполняет чат, шлюз R2 не используется.

## Последствия

Публичные discovery/регистрация требуют пределов и ограниченных размеров входа. Успех локального протокольного теста не доказывает доступность реального туннеля или подписки клиента; включение рабочего дома и проверка на телефонах принадлежат владельцу.

## Отклонённые варианты

Отдельный участник ИИ, общий ключ дома, передача пароля чату и прямое сохранение записей: нарушают персональный доступ, отзыв или обязательное подтверждение.
