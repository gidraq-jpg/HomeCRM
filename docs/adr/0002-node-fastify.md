# ADR-0002. Node 24 LTS и Fastify 5

- **Статус:** принято, 5 октября 2026
- **Связано:** план, T2; D12

## Контекст

Нужен сервер на TypeScript (D12) со зрелыми модулями для cookie, ограничения запросов, загрузки файлов и заголовков безопасности. Код пишут агенты, поэтому важна распространённость.

## Решение

- **Node 24 LTS:** поддержка до апреля 2028 года, встроенный запуск TypeScript (ADR-0016).
- **Fastify 5:**
  - схемы запросов и ответов;
  - `inject` для тестов без сети;
  - официальные модули: cookie, ограничение запросов, загрузка файлов, заголовки безопасности.
- Сервер слушает только `127.0.0.1`. Порты: разработка — 8310, предпросмотр — 8301, рабочее окружение — 8300.

## Последствия

- Проверка доступа и контекст пользователя оформляются как хуки Fastify, общие для всех маршрутов.
- `buildApp()` создаёт приложение без запуска сети — так его проверяют тесты.

## Отклонённые варианты

- **Hono** — легче, но модулей для cookie-сессий и загрузки файлов меньше. Остаётся запасным вариантом.
- **Express** — медленнее, нет встроенных схем.
- **NestJS** — слишком много каркаса для семейного приложения.
