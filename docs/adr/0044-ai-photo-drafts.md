# ADR-0044. Фото в проверяемые черновики

- **Статус:** принято для реализации D26, 25 октября 2026
- **Связано:** AI-2…AI-8, UTIL-4/5/9, ADR-0043

## Решение

Фото проходит JPEG-преобразование до 1600 px без метаданных; содержимое остаётся
в памяти запроса. Перед извлечением выполняется отдельная проверка документа
личности с единственным полем `identity: yes | no | unsure`. Да и сомнение
останавливают извлечение. Обе операции делят срок 120 секунд и один расход
дневного предела разбора. Отказ поставщика не возвращает расход.

Числа на табло модель возвращает строками. Разрядность проверяет сервер существующими
`meterUnits`/`meterDecimal`, не применяя арифметику с плавающей точкой. Несоответствие
становится пустым неуверенным полем. Результат заполняет обычную форму; сохранение,
проверки уменьшения/аномалии и приложение выбранного фото используют прежние API
и офлайн-очередь показаний. Отдельного временного хранилища фото нет.

Согласие общее для текста и фото, с версией, участником, домом и отпечатком поставщика.
Поля контекста зависят от операции: для табло — только параметры счётчика и прошлые
значения, для проверки личности — никаких записей приложения.

## Защита предела при FORCE RLS

Миграция 0068 сохраняет политики существующих пользовательских сущностей.
Приложение не получает UPDATE/DELETE счётчика. INSERT вызывает проверку членства,
включения ИИ и дня в поясе дома с правами вызывающего, затем закрытый триггер
владельца атомарно заменяет дневную строку числом `прежнее + 1` под блокировкой дня.
Это эквивалент защищённой функции расхода: прямой INSERT также проходит проверку
и не может уменьшить число. Доступ владельца к счётчику разрешён только внутри
триггера; доступа к пользовательским таблицам он не получает.

## Последствия

Проверка личности добавляет вызов модели, но исключает извлечение полей при сомнении.
Синтетические табло проверяются через `pnpm ai:eval --kind=meter`, проверка личности —
`--kind=identity`; CI использует только контракт fake. Качество настоящих фото и камера
телефона остаются отдельной проверкой владельца перед включением сценария.
