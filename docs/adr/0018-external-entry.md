# ADR-0018. Внешний вход и адрес приложения

- **Статус:** предложено, 5 октября 2026; решение — по замерам задачи 0.2
- **Связано:** план, задачи 0.2 и 0.6, раздел 7; PRD D11, D15, D16, A4

## Контекст

- Сервер работает на этом компьютере (D11). Входящие порты наружу не открываются.
- С июня 2025 года российские провайдеры замедляют Cloudflare и зарубежные хостинги: часто загружаются только первые 16 КБ.
- У семьи есть VPS в России и за рубежом (D15).
- Адрес — поддомен существующего домена (D16). Push-подписки и установленные PWA привязаны к адресу, поэтому он закрепляется до первых настоящих подписок.

## Варианты для замера

| Вариант | Как устроен |
|---|---|
| А1 | Российский VPS: Caddy с автоматическим HTTPS и обратный SSH-туннель с этого компьютера |
| А2 | Зарубежный VPS: то же самое |
| Б | Временный Cloudflare Tunnel со случайным адресом — только для сравнения |

## Как устроен вход через VPS

1. **На компьютере** контейнер `tunnel` держит SSH-соединение с VPS и пробрасывает порт приложения на `127.0.0.1:18300` самого VPS. После обрыва соединение восстанавливается само.
2. **На VPS** для туннеля — отдельный пользователь без оболочки. Его ключ может открыть только этот порт на `127.0.0.1`: ни команд, ни других пробросов.
3. **Caddy** на VPS получает сертификат Let's Encrypt и передаёт запросы в туннель. Служебные адреса заглушки снаружи закрыты.
4. **DNS:** `home.<домен>` → российский VPS, `home-alt.<домен>` → зарубежный, на время замеров. Если победит зарубежный, `home.<домен>` перенаправляется на него.

## Решение

Принимается после замеров по правилу из плана (раздел 4, этап 0):

- основной кандидат — российский VPS;
- зарубежный — только если на всех четырёх телефонах и у всех операторов не хуже;
- Cloudflare Tunnel — только для сравнения;
- VPS, который не стал входом, хранит резервные копии и держит внешнего сторожа.

Результаты — в [таблице замеров](../stage0/access-measurements.md).

## Последствия

- Секреты туннеля — ключ и отпечаток сервера — лежат в `E:\HomeCRM-data\secrets\tunnel`.
- После переезда сервера на VPS туннель больше не нужен: Caddy передаёт запросы приложению напрямую, адрес не меняется.

## Отклонённые варианты

- **Открыть порт на домашнем роутере** — домашний IP раскрыт, Windows 10 без основной поддержки торчит в интернет.
- **Cloudflare Tunnel как основной вход** — замедление в России.
