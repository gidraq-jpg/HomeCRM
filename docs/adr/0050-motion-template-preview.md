# ADR-0050. Эксперимент локальной смены содержимого

- **Статус:** предложено, 3 ноября 2026; только тестовый стенд, рабочее принятие ожидается.
- **Связано:** UI-8, ADR-0045, ADR-0049.

Существующие токены 160/240/450/330/330/560/300 мс и единая кривая сохраняются.
Множитель ×2 из примера не переносится. Нижнее меню, боковая навигация, история и листы остаются по ADR-0049.

Второй проход разрешён владельцем 3 ноября: применить [полную карту из 24 сценариев](../tasks/ui-8-motion-template-round2.md) в текущем тестовом макете. Нажатие вкладок лент использует последовательную локальную смену вместо проката карусели; направление зеркально порядку вкладок. Свайп этих же лент остаётся физическим движением за пальцем с доездом 450 мс и отменой 330 мс. Смонтированные соседние ленты, их данные и черновики сохраняются.

Шапка удерживает геометрию, текст меняется затуханием за 160 мс. Индикатор локальной вкладки перемещается за 240 мс от текущего видимого положения, включая быстрый повторный выбор.

Для локальной смены результатов используется ContentMotion: данные обновляются сразу,
прежний inert/aria-hidden снимок выходит за fast; строки нового результата входят за base
с очередью base/5, ограниченной тремя шагами. Фильтр отвечает сразу. Одинаковый ключ
не перезапускает движение. При новом результате предыдущая последовательность отменяется;
в актуальном DOM остаётся единственный доступный слой. Сравниваются только ключи конечных строк, не заголовки групп. До окончания выхода удерживается прежняя высота: пустое состояние не обрезает снимок, соседнее содержимое меняет место после выхода. Завершение старого перехода защищено поколением и не может снять высоту нового. Reduced motion — только fast-затухание.
Пустое состояние включено в ту же границу. Снимки хранятся только в памяти компонента.

Общая граница смены покрывает реальные списки и их пустые состояния, включая поиск, радар и месячную сводку. Сохранившиеся строки не появляются заново; перестановка существующих строк занимает base. График продолжает переход от видимой высоты, а не от предыдущей цели. Движение родителя и строки не складывается на одном содержимом. Повторная загрузка не запускает заново появление уже показанных данных.

Обратная связь операции рисует настоящее состояние существующей кнопки за fast с сохранением её размера. Успех наступает только после подтверждения операции приложением; движение не добавляет искусственного ожидания и не задерживает уход со страницы. Срок доступности отмены остаётся прежним.

Для прерывания действует последнее действие. Уборка предыдущего перехода не удаляет новый снимок и не сбрасывает его размеры. В актуальном дереве сразу доступны новые данные, адрес и фокус; снимки inert/aria-hidden, без повторяющихся id. При уменьшении движения нет геометрических переходов и очереди, только fast-затухание.

Проверка второго прохода: Linux Playwright 360/412 px, обычное и уменьшенное движение; нажатия вперёд/назад, свайп, быстрые переключения, перестановка, прерывание графика, пустые состояния, axe, цели 44 px и отсутствие горизонтального переполнения. Итоги и фактические ограничения фиксируются в брифе. Изменение остаётся локальным до просмотра владельцем.

Принятие владельцем и проверка физических PWA остаются после просмотра изолированного стенда.
