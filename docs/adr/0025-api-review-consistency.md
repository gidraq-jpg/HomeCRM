# ADR-0025. Доработки API объектов и согласованность загрузки файлов

- **Статус:** принято, R0.5d, 7 октября 2026
- **Связано:** OBJ-1…4, SPACE-7, ADR-0023, ADR-0024

## Контекст

Ревью R0.5a–R0.5c выявило запросы на каждый конец связи и каждую экспортируемую карточку, фильтр корзины после LIMIT, длительную блокировку родителя во время передачи файла и риск удаления живых блоков при потере ответа COMMIT.

## Решение

Списки связей соединяются с проекцией зарегистрированных видов записей под RLS. Концы содержат прежние type/id и дополнительно название, вид объекта и корзину. Видимость обоих концов и корзина проверяются до LIMIT/OFFSET. Экспорт сохраняет JSON версии 1, но обходит объекты, ленту и связи страницами по 100, а поля и файлы читает на пачку объектов.

Миграция 0019 сохраняет строки и историю. Каскад событий использует WHERE parent_id текущего объекта. Узкая SELECT-политика разрешает вложенному триггеру обработать события с недоступным снимком происхождения; прямой SQL и поддельные настройки транзакции прав не получают. record_guard отклоняет неизвестную таблицу; тест сверяет перечень со всеми recordTable. Явный null снимает ответственного общего объекта; личное сохраняет владельца по PRD 7.3.9.

Дополнение к ADR-0024: приём файла, проверка формата, превью и шифрование происходят вне транзакции записи. В короткой транзакции повторно проверяются права и корзина под FOR UPDATE родителя, затем записываются готовые зашифрованные блоки и метаданные. При ошибке тела выполняется немедленная компенсация. После успешного тела исход COMMIT может остаться неизвестным: блоки сохраняются до сверки обработчиком с file_blobs. Это заменяет немедленное удаление при любой ошибке COMMIT из ADR-0024. Живая строка всегда сохраняет содержимое; достоверно осиротевшие блоки удаляются существующим обслуживанием после часа.

Дешифрование GCM требует тег 16 байт. Фото и превью сохраняют ICC-профиль, удаляя EXIF/GPS/XMP; sharp с failOn:error принимает JPEG с предупреждениями, но отклоняет ошибки декодирования. Тест использует искусственную картинку с лишними байтами между JPEG-маркерами. API и метаданные файлов совместимы с R0.5b.

## Последствия

Неизвестный исход COMMIT может временно оставить осиротевший зашифрованный блок, но не уничтожает живой файл. Экспорт по-прежнему собирает полный JSON в памяти ответа; потоковый архив относится к R0.10. Обработка HEIC, лимиты входа и пикселей прежние; пул обработчиков остаётся в бэклоге. Новых зависимостей нет.
