# ADR-0007. Клиент: React 19, Vite и библиотеки интерфейса

- **Статус:** принято, 5 октября 2026
- **Связано:** план, T7; PRD, разделы 13–14

## Контекст

Интерфейс — PWA для телефона на ширине от 360 px и для компьютера (PRD, раздел 14). Дизайн уже выбран в LifeOS: мобильный прототип в стиле Calm Focus.

## Решение

- **React 19 и Vite 8.**
- **TanStack Query** — данные с сервера: кэш, повторы, офлайн-режим.
- **React Router** — маршруты.
- **Radix UI** — доступные примитивы: диалоги, меню, переключатели.
- **Phosphor** — иконки.
- **Токены Calm Focus** — переносятся из мобильного прототипа LifeOS в R0.3.

## Последствия

- Доступность закладывается в примитивах, а не дописывается потом (WCAG 2.2 AA).
- Каждый блок экрана со своей загрузкой и ошибкой: сбой одного не ломает экран (урок LifeOS).

## Отклонённые варианты

- **Next.js** — серверная отрисовка не нужна: PWA и API проще.
- **Vue или Svelte** — агенты и прототип LifeOS уже на React.

## Экраны входа в R0.3a

TanStack Query добавлен для независимых блоков профиля (устройства и журнал) и проверки сессии.
Кэш только в памяти, без persistence, `gcTime: 0`; при выходе очищается. Формы имеют отдельные
состояния отправки и ошибки, без автоматического повтора и кэша мутаций с паролями и кодами.
zod проверяет ответы API на границе клиента. `qrcode` строит QR второго фактора локально:
секрет не отправляется на внешние сайты. Код, пароль, QR и ссылки не записываются в браузерные
хранилища. Связанные с входом маршруты и настройки работают с API; остальные разделы пока
остаются вымышленным прототипом до следующих задач R0.
