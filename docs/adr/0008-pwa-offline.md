# ADR-0008. PWA: свой service worker, офлайн в IndexedDB

- **Статус:** принято, 5 октября 2026
- **Связано:** план, T8 и раздел 2.6; PRD, раздел 13

## Контекст

Нужны push-уведомления, чтение без сети и очередь записей без сети: дела, заметки, показания с фото. Готовые стратегии кэширования это не покрывают.

## Решение

- **vite-plugin-pwa в режиме `injectManifest`:** свой service worker на TypeScript, плагин только добавляет список файлов для кэша.
- **Service worker** отвечает за кэш оболочки, push, нажатие на уведомление и повтор отправки очереди.
- **IndexedDB через Dexie:**
  - кэш для чтения: «Сегодня», радар, последние открытые карточки;
  - очередь записей с ключами идемпотентности.
- **Генератор идентификаторов** работает и там, где нет `crypto.randomUUID` (урок LifeOS).
- При выходе локальные данные учётной записи удаляются; о неотправленном приложение предупреждает.

## Последствия

- Сервер хранит квитанции ключей идемпотентности: повторная отправка из очереди не создаёт дублей.
- Конфликты правок видны пользователю, а не решаются молча.

## Отклонённые варианты

- **Стратегия `generateSW`** — нет места для своей логики push и очереди.
- **Нативное приложение** — не планируется (PRD, раздел 5).
