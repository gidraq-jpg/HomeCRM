# ADR-0010. Файлы: шифрование и хранилище за интерфейсом

- **Статус:** принято, 5 октября 2026
- **Связано:** план, T10 и раздел 2.7; PRD OBJ-4, раздел 13

## Контекст

Фото счётчиков, квитанции, сканы документов — чувствительные данные. В LifeOS статические файлы отдавались без проверки доступа; здесь так нельзя. Сейчас файлы живут на этом компьютере, позже — на VPS или в S3-совместимом хранилище.

## Решение

- **Хранилище — том Docker** за интерфейсом «положить, взять, удалить по ключу». Ключ хранения — случайный и не связан с названием файла.
- **Шифрование конвертом:**
  - у каждого файла свой ключ AES-256-GCM;
  - ключи файлов зашифрованы главным ключом из `E:\HomeCRM-data\secrets`;
  - превью шифруются так же.
- **Превью** — через sharp; на телефоне фото уменьшаются до 2560 px перед загрузкой, предел — 25 МБ.
- **Выдача** — только через маршрут с проверкой доступа (ADR-0004). Для чувствительных файлов браузер не кэширует ответ.

## Последствия

- Без главного ключа файлы из резервной копии не восстановить. Ключ хранится в менеджере паролей и на бумажном листе восстановления.
- Смена хранилища на S3-совместимое не затрагивает остальной код.

## Отклонённые варианты

- **Файлы в базе** — раздувают базу и её копии.
- **Без шифрования** — копия тома или резервная копия раскрывала бы всё.
