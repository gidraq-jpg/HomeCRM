## Границы существующих данных

- Чисел у фильтров дел нет в ответе списка: кнопки без чисел. Сводка открытых дел показывается только для полностью загруженного списка без серверных фильтров. Сводка покупок также не выдаёт частичную страницу за полный итог. Число заметок с незагруженными страницами обозначено `N+`.
- Список дел не содержит объекта и имени другого исполнителя. Название объекта пропущено; имя показывается только из уже имеющегося кэша участников. Новый запрос ради подписи не добавлен.
- Для основного дома используется пояс `me.timeZone`. При выборе другого дома берётся пояс уже загруженного «Сегодня»; если его нет в кэше, список показывается без временных групп, без запроса ради группировки.
- Список заметок не содержит текста, чек-листа, количества файлов и связанного объекта. В закреплённых остаются название и аудитория; в недавних — название, дата и аудитория. Нулевой прогресс и фиктивные файлы не рисуются.
- Список покупок содержит ID автора, но не его имя, род и связи с делом. Эти подписи пропущены. Название, количество, заметка, категория и магазин берутся из прежнего ответа.

## Переиспользование и проверка

«Все дела» используют `PlanRows`; радар и недавние заметки — `RowContent`/`RowList` и `Row`. Обёртка строк полного радара отделена от прежнего `RadarRows`, чтобы сохранить блок «Сегодня». Поверка и переход к счёту/счётчику остаются в меню действий. Общая `TaskTabs` отвечает за четыре вкладки, видимый «+» и прокрутку активной вкладки при увеличении текста. Адрес покупок сохранён.

Приёмочные сценарии — `apps/web/e2e/app/studio2-lists.e2e.ts`: данные и пустота, 100/200%, фильтр дел, группы и действие радара, меню с причиной, покупки по Enter, отмена отметки, чтение без сети, закреплённые заметки и доступ ребёнка. Затронутые прежние регрессии сохраняют проверки 409, денежных операций, времени, офлайна и смены пользователя.

Локально проверены 20/20 затронутых модульных тестов и 32 уникальных сквозных сценария приёмки и регрессий на обеих ширинах. В отдельном наборе проверены отмена выполнения, задержанный refetch и смена аккаунта. Итог полного `pnpm check` и независимого CI — в описании PR.

Запуск из корня выделенного worktree:

```powershell
docker compose -f apps/web/e2e/studio2-lists/compose.yaml run --rm playwright pnpm --filter @homecrm/web test:e2e:auth studio2-lists.e2e.ts
```

Compose-проект `homecrm-test-ui-5-studio2-lists` использует свою PostgreSQL и случайный порт. Проверка на физических телефонах и выпуск в рабочее окружение в эту задачу не входят.
