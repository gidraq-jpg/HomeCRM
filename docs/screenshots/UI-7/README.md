## Реализация

- `StudioPage`, `RecordPage` и каркас объекта используют одну `FormHeading` и признак `ui7-fullscreen-form`. Оболочка скрывает верхнюю строку, dock и боковое меню только у формы на ширине <1024 px; на 1280 px боковое меню остаётся.
- `FormSubmitBar` оборачивает существующую submit-кнопку внутри прежнего form/fieldset. Основная кнопка закреплена над safe-area; вторичные действия остаются в форме. При клавиатуре панель переходит в поток после полей.
- `useKeyboardAttribute` сбрасывает высоту при настоящем повороте устройства. Media query ориентации меняется также от низкого окна клавиатуры и раньше могла ошибочно вернуть dock/фиксированную панель на 412 px.
- Поля используют токены высоты 48 px и радиуса 16 px. Многострочные поля сохраняют строки и возможность роста; быстрый ввод начинается с одной строки и растёт при увеличении текста. Подсказки добавлены без замены подписей.
- Факты `RecordPage` используют сетку с минимальной шириной в rem: при увеличении текста значения переносятся целиком.
- Адреса возврата и существующие обработчики сохранения, pending/disabled, черновиков, офлайна и 409 сохранены. Новых зависимостей нет. Прежние e2e и проверки доступа не ослаблены.

## Проверки и воспроизведение

```powershell
docker compose -f apps/web/e2e/fullscreen-forms/compose.yaml build playwright
docker compose -f apps/web/e2e/fullscreen-forms/compose.yaml run --rm playwright pnpm --filter @homecrm/web test:e2e:auth -c e2e/fullscreen-forms/playwright.config.ts --workers=1
docker compose -f apps/web/e2e/fullscreen-forms/compose.yaml down
```

Сценарии 100% и 200% имеют независимые семьи и браузерные сессии. Для каждой формы: axe, цели 44 px, отсутствие горизонтальной прокрутки, сохранение/создание, прежний адрес «Назад»; для создания также история браузера. На телефоне проверяется полная видимость основной кнопки без прокрутки и отсутствие перекрытия последнего поля при высоте окна 450 px. Проверка бокового меню на 1280 px находится в общем наборе `desktop.e2e.ts`. Высота полей формы дела, входа и быстрого добавления проверяется численно.

## Исправления по ревью PR #68

- Полноэкранный режим объекта включается только на «Обзоре»: возврат «Лента → Править → goBack» возвращает вкладки, верхнюю строку и dock. Отдельный e2e проверяет это на 360/412 px.
- Выбор шаблона остаётся обычным списком; в шапке формы виден выбранный шаблон, в правке документа — прежний статус. Снимки этих двух форм и коллажи обновлены.
- После смены ориентации базовая высота клавиатуры обновляется на ближайшем resize; без screen.orientation используется matchMedia. Оба варианта проверены модульными тестами. Быстрая строка растёт по содержимому.
- Общий CI запускает короткий набор `app/fullscreen-forms.e2e.ts`: каждая форма открывается, проходит axe, сохраняется; кнопка видна, dock скрыт. Полная матрица 100/200%, возврат, клавиатура и высота полей — только `fullscreen-forms/full-matrix.ts` через свой compose-конфиг выше; 1280 px — `desktop.e2e.ts`. Лимит общего e2e — 45 минут с учётом подготовки контейнера и нагрузки runner.
- Проверки ревью: типы, кодировка и `pnpm test:changed` — 32/32; Linux короткий набор + возврат объекта + desktop — 7/7. После доводки шапки матрица — 9/10; исправленный перенос названия шаблона на 360 px/200% проверен отдельно — 1/1, все десять сценариев проходят. Итог штатного pre-push и CI — в PR.

## Ограничения

Отдельного предупреждения о несохранённых полях раньше не было, оно не добавлено. Прежнее предупреждение при незавершённой офлайн-очереди остаётся.
