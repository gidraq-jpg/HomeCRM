## Реализация

- `StudioPage`, `RecordPage` и каркас объекта используют одну `FormHeading` и признак `ui7-fullscreen-form`. Оболочка скрывает верхнюю строку, dock и боковое меню только у формы на ширине <1024 px; на 1280 px боковое меню остаётся.
- `FormSubmitBar` оборачивает существующую submit-кнопку внутри прежнего form/fieldset. Основная кнопка закреплена над safe-area; вторичные действия остаются в форме. При клавиатуре панель переходит в поток после полей.
- `useKeyboardAttribute` сбрасывает высоту при настоящем повороте устройства. Media query ориентации меняется также от низкого окна клавиатуры и раньше могла ошибочно вернуть dock/фиксированную панель на 412 px.
- Поля используют токены высоты 48 px и радиуса 16 px. Многострочные поля сохраняют строки и возможность роста; быстрый ввод начинается с одной строки и растёт при увеличении текста. Подсказки добавлены без замены подписей.
- Факты `RecordPage` используют сетку с минимальной шириной в rem: при увеличении текста значения переносятся целиком.
- Адреса возврата и существующие обработчики сохранения, pending/disabled, черновиков, офлайна и 409 сохранены. Новых зависимостей нет. Прежние e2e и проверки доступа не ослаблены.

## Проверки и воспроизведение

```powershell
docker compose -f apps/web/e2e/fullscreen-forms/compose.yaml build playwright
docker compose -f apps/web/e2e/fullscreen-forms/compose.yaml run --rm playwright pnpm --filter @homecrm/web test:e2e:auth -c e2e/fullscreen-forms/playwright.config.ts --workers=1
docker compose -f apps/web/e2e/fullscreen-forms/compose.yaml down
```

Сценарии 100% и 200% имеют независимые семьи и браузерные сессии. Для каждой формы: axe, цели 44 px, отсутствие горизонтальной прокрутки, сохранение/создание, прежний адрес «Назад»; для создания также история браузера. На телефоне проверяется полная видимость основной кнопки без прокрутки и отсутствие перекрытия последнего поля при высоте окна 450 px. На 1280 px проверяется боковое меню. Высота полей формы дела, входа и быстрого добавления проверяется численно.

Локально: `pnpm test:changed` — 24/24; Linux UI-7 — 15/15 сценариев на 360/412/1280 px, axe без серьёзных и критичных замечаний; типы и кодировка проходят. Полный `pnpm check` выполняется штатным pre-push hook, независимый итог CI — в PR.

## Ограничения

Отдельного предупреждения о несохранённых полях раньше не было, оно не добавлено. Прежнее предупреждение при незавершённой офлайн-очереди остаётся. Экранная клавиатура проверена уменьшением viewport; Android/PWA с настоящей клавиатурой и вырезом экрана проверяет владелец после выпуска. Рабочее окружение не менялось.
