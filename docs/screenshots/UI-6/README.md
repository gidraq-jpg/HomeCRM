## Применённые компоненты и границы

- Строки списков используют существующие `ui/Row.tsx` и `RowList`, как UI-4/D15. `PlanRows` рассчитан на дела: тип TaskCard, выполнение, перенос, исполнители. Для контактов, объектов и документов он не подходит; новых компонентов строк нет.
- `RecordPage` объединяет шапку по образцу Object и лист действий; `StudioPage` — общий каркас списков и форм. Они принимают прежние обработчики/содержимое, не делают запросов.
- `FilesSection.compact` применяется только к делу, заметке и документу D16a. Прежняя композиция файла для остальных экранов, включая объект, сохранена. Все новые стили ограничены классами UI-6 в `studio2.css`; радиусы вынесены в токены.
- Информационная метка человека/организации — уточнение ведущего от 17 октября. Для заметки остаётся NoteAccess, у дела — прежняя панель изменения доступа, у личного документа — прежний блок «Поделиться со взрослыми».
- Нет новых агрегатов/запросов. В шапках нет количества связанных записей, расходов, сумм и иных показателей, которых нет в загруженной карточке; отсутствующие день рождения и часы работы не подменяются вымышленными значениями.

## Решения исполнителя, на утверждение

1. Композиция пяти карточек заимствует Object; факты выбираются по назначению: план/срок/повтор дела, автор/дата/чек-лист заметки, автор/дата/день рождения человека, владелец/срок/ответственный документа, автор/дата/часы организации.
2. Выполнение/отмена/возобновление дела, продление документа и быстрый звонок контакту остаются основными действиями в светлой части. Правка — в шапке, остальные прежние действия — в «Ещё».
3. Полные формы имеют ту же тёмную шапку и общий тёплый лист; вторичные действия текстом. Листы и подтверждения используют прежний Sheet, без новых шагов подтверждения.

### D16b: решения исполнителя, на утверждение

- Служебные формы и справочные разделы используют группы на `--surface`, как списки System; существующие подписи и подтверждения сохраняются. `PlanRows` принимает дела, поэтому для сводок использованы общие `Row`/`RowList`; новых компонентов строк нет.
- Начисления остаются разделом внутри карточки объекта. Отдельная тёмная шапка дала бы вложенный экран; изменён только внутренний раздел, оболочка объекта не менялась.
- Для «Ещё» обратная ссылка ведёт на «Сегодня», для поиска и отсутствующего адреса — на «Ещё», для открытия уведомления — на «Ещё»; отдельная прежняя кнопка открывает радар. Адреса прежних действий не менялись.
- Новый пункт 10 контракта (полноэкранные формы, D18) относится к отдельной задаче UI-7; область D16b — пункты 1–9 по брифу.
- Нет новых запросов и агрегатов для оформления. Нет недоступных счётчиков записей, сумм, ролей и иных вымышленных данных; используются только уже загруженные ответы. Состояние доступа заметки поднято выше меню, существующий probe сужения доступа сохранён и остаётся ленивым. `Sheet.returnFocusRef` возвращает фокус к устойчивой кнопке «Ещё»; закрывающийся лист не забирает фокус у следующего открытого.
