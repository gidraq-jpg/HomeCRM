# D49 — «План» как ежедневник

Linux Playwright, тема Studio, ширины 360 и 412 px; высота окна 800 px.

- `today-w360.png`, `today-w412.png` — первое открытие на сегодня без запроса прошлого и программной прокрутки.
- `sticky-w360.png`, `sticky-w412.png` — прилипшие вкладки и неделя; на 360 × 800 видно не менее пяти строк.
- `history-w360.png`, `history-w412.png` — история выполненного и пустые прошлые дни.
- `undated-w360.png`, `undated-w412.png` — лист «Без даты» и возраст дела.
- `review-w360.png`, `review-w412.png` — воскресная карточка разбора на «Сегодня».

Сценарий: `apps/web/e2e/app/plan-diary.e2e.ts`. Воскресенье задаётся в ответе API только в тесте.
Снимки созданы заново для D49, только на вымышленных данных. Серьёзных и критичных замечаний axe нет.
