проверены отсутствие горизонтальной прокрутки и цели нажатия от 44 px. QR, ключи, резервные
коды и заполненные поля паролей скрыты. Длинные страницы сняты с увеличенной высотой окна,
чтобы липкая шапка и нижнее меню стояли по краям страницы.
