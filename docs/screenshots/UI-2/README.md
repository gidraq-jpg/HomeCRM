Проверено 14 октября 2026 в отдельном compose-проекте `homecrm-test-ui-2-studio`.

Команда целевого мобильного прогона внутри Linux-контейнера:

```sh
cd /workspace/apps/web
node e2e/run.ts app e2e/app/tasks-layout.e2e.ts --project=w360 --project=w412 --grep "пустые ленты|быстрая строка|заполненные ленты|Studio:" --workers=2
```

Финальное подтверждение после изменения локального фона:

```sh
node e2e/run.ts app e2e/app/tasks-layout.e2e.ts e2e/app/desktop.e2e.ts --project=w360 --project=w412 --project=desktop --grep "Studio:|боковое меню вместо нижнего" --workers=2
```
