# D40 — прикрепление исходного файла

Снимки Linux Chromium, вымышленная семья. В папках `360` и `412` — ширина окна в px.

- `draft-true` / `draft-false`: черновик с включённой и снятой отметкой.
- `object-true` / `object-false`: форма нового объекта сохраняет выбор отметки.
- `saved-true` / `saved-false`: сообщение после окончательного сохранения черновика.

Проверки: Playwright, отсутствие горизонтальной прокрутки, цели от 44 px, axe без серьёзных и критичных замечаний.
Новый объект создаётся и запоминается сервером без повторов; исходные файлы остаются во «Входящих» до окончательного сохранения записи. При сохранении копии для записи и нового объекта фиксируются вместе, исходные блоки удаляются после COMMIT. При разных пространствах или аудиториях копия в новый объект не создаётся.

Отдельного пути распознавания при создании объекта или документа вне «Входящих» нет: обычные формы создают запись, а раздел вложений загружает файл к уже существующей записи.
