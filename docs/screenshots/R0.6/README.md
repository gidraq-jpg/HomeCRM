# Поиск R0.6

`apps/web/e2e/app/search.e2e.ts`: 3 сценария × 2 ширины, axe без серьёзных и критичных замечаний, нет горизонтальной прокрутки, цели нажатия от 44 px. Проверены копирование телефона, переход в карточку, смена режима, отсутствие запроса в адресе, storage и Cache API, сброс строки после перезагрузки. Обновлён существующий сценарий входа/закрытия поиска в `shell.e2e.ts`: ещё 2 проверки.

Выбор записи для связи остаётся в бэклоге R0.5c: он использует отдельные сведения для проверки `canWriteLink`, которых в краткой поисковой выдаче нет. Перевод выбора требует отдельного контракта кандидатов и проверки прав на оба конца; первые 100 объектов и заметок здесь не изменены.
