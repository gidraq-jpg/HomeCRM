# D39: кадры движения на 360 px

Кадры сняты Chromium в Linux-контейнере Playwright, только на вымышленной семье.
`section`, `card`, `back`, `form`, `feed`: начало, середина и конец перехода.
Для экранов середина соответствует 40 % длительности; для ленты — положению под пальцем.
Скриншоты снимаются через CDP, чтобы не завершать View Transition перед снимком.

В сценарии экранов включено замедление CPU ×4. Проверены границы окна, раннее проявление,
обратное движение и уменьшение движения; это не замер FPS физического Android.
Размытие не применяется: используются равномерный масштаб 0,97 и яркость 0,9.
При `hasUAVisualTransition` собственная анимация системного возврата пропускается.
Predictive back и вибрация на физическом телефоне остаются для приёмки владельцем.

Старые сценарии обновлены: вместо изменения размеров `.main` проверяется окно снимка;
геометрия снимка отделена от живой высоты страницы при загрузке истории и файлов.
Ожидание `settle` учитывает предзагрузку; строки ищутся в активной заранее отрисованной ленте.

Правый и нижний отступы маски заданы через `calc(100% - координата источника)`: поздняя догрузка не меняет окно. В e2e высота карточки принудительно увеличивается между обновлением маршрута и захватом снимка.
