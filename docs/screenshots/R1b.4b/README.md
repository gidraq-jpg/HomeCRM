# R1b.4b–5b: импорт vCard, дни рождения и долги клиента

Снимки сделаны в Linux-контейнере `mcr.microsoft.com/playwright:v1.63.0-noble` на вымышленной семье: Анна, Борис и Вера. Ширины 360 и 412 px. На каждом снимке проверены axe (без серьёзных и критичных нарушений), цели от 44 px и отсутствие горизонтальной прокрутки. Рабочее окружение не использовалось.

Сценарии — `apps/web/e2e/app/vcard-birthdays.e2e.ts`. Они проверяют повтор после потерянного ответа (vCard, начисление и оплата), три карточки и одно совпадение, битый файл, смену видимости, день рождения с годом и без, «Сегодня», настройку профиля, права ребёнка, сохранение скрытых связей, поиск, корзину, остаток начисления, отмену по `paymentId`, режимы месячной коммуналки, имена владельцев и файлы документа, границу паспорта из API и имя контакта в ленте без отдельных запросов.

Импорт доступен в «Людях» → «Импорт из файла». Для совпадений с более широкой аудиторией, чем в «Кто видит», показан фактический доступ и по умолчанию выбрано «Создать отдельно». Объединение с такой целью требует подтверждения доступа к добавленным телефонам, дате рождения и заметке; обещание приватности заменено пояснением о доступе цели. Смена решения или обновление предпросмотра сбрасывает подтверждение. Аудитория читается через существующий API карточки и сверяется с редакцией из предпросмотра. Для остальных совпадений нужно явно выбрать объединение или создание отдельного контакта. Смена «Кто видит» сбрасывает предпросмотр; перед импортом его нужно обновить. Файл, содержимое, предпросмотр и ключи повторов живут только в памяти открытой формы. Уход с экрана закрывает текущую операцию; между повторными отправками неизменённой формы ключ сохраняется. Проверки запрещают попадание содержимого в консоль, адрес страницы, localStorage и кэш сервис-воркера.

Регрессия блокера PR #48: общий контакт и vCard с совпадающим телефоном, новым телефоном, датой рождения и заметкой при «Только я». На обеих ширинах проверены личная копия по умолчанию и недоступность новых полей ребёнку; отдельный сценарий подтверждает предупреждение до отправки, блокировку без флажка, сброс подтверждения и фактическую общую аудиторию после подтверждённого объединения. Прогон этого файла: 20/20, включая четыре проверки блокера; axe без серьёзных и критичных нарушений, цели не меньше 44 px, горизонтальной прокрутки нет.

Удалённые люди доступны в «Ещё» → «Корзина». Корзина взаимодействий открывается в карточке контакта: готовое API выдаёт удалённые взаимодействия только по контакту, общего списка нет. Возвращение контакта восстанавливает записи, удалённые вместе с ним; отдельно удалённые взаимодействия возвращаются отдельно.
