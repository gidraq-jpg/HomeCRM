# R1a.9b — «Коммуналка за месяц», аналитика объекта, документы: экраны

Снимки сделаны Chromium на вымышленной семье (Анна — администратор, Борис — взрослый, Вера и Петя — дети) сценариями `app/utility-month.e2e.ts` и `app/documents.e2e.ts` на ширине 360 и 412 px. Axe: без серьёзных и критичных нарушений; цели от 44 px, горизонтальной прокрутки нет. Серии и номера в снимках вымышленные и скрыты до нажатия «Показать». Снимки сделаны на компьютере владельца (Windows), а не в контейнере Playwright: для сравнения с эталоном они не годятся, только для просмотра. Рабочее окружение не использовалось.
