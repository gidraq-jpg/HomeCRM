# UI-3 — Linux-представители Studio

Снимки сняты существующими Playwright-сценариями в Linux-контейнере; фикстуры содержат только вымышленную семью. Каждый мобильный представитель проверен на 360 и 412 px с axe. Аналитика проверена на 1280 px.

| Семейство | Представитель | Проверка |
|---|---|---|
| Вход и формы | Вход | 360/412, axe, отсутствие переполнения, цель нажатия; логотип Studio сохранён |
| Список и карточка объекта | Карточка объекта | 360/412; вкладки переносятся, действия доступны |
| Документы | Карточка документа | 360/412; конфиденциальные номера остаются замаскированы |
| Показания и статусы | Архив показаний | 360/412, axe; статус читаем |
| Заметки и формы | Форма заметки | 360/412, axe |
| Настройки и опасные действия | Исключение участника | 360/412; текст действия и подтверждение видимы |
| Табличное представление | Аналитика | 1280 px; таблица и диаграмма помещаются |

Итог целевого прогона: первоначально 10/16 сценариев прошли; после исправления контраста повторены только шесть упавших сценариев — 6/6. После последнего изменения заголовка вход проверен вместе с axe на обеих ширинах — 4/4 (вход и выбранное действие исключения участника). Десктоп — 1/1. Полный `pnpm check` и общий визуальный прогон оставлены для согласованного окна перед отправкой.
