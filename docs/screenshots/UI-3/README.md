# UI-3 — Linux-представители Studio

Снимки сняты существующими Playwright-сценариями в Linux-контейнере; фикстуры содержат только вымышленную семью. Каждый мобильный представитель проверен на 360 и 412 px с axe. Аналитика проверена на 1280 px.

| Семейство | Представитель | Проверка |
|---|---|---|
| Вход и формы | Вход | 360/412, axe, отсутствие переполнения, цель нажатия; логотип Studio сохранён |
| Список и карточка объекта | Карточка объекта | 360/412; вкладки переносятся, действия доступны |
| Документы | Карточка документа | 360/412; конфиденциальные номера остаются замаскированы |
| Показания и статусы | Архив показаний | 360/412, axe; статус читаем |
| Заметки и формы | Форма заметки | 360/412, axe |
| Настройки и опасные действия | Исключение участника | 360/412; текст действия и подтверждение видимы |
| Табличное представление | Аналитика | 1280 px; таблица и диаграмма помещаются |

Граница доказательств: общий нейтральный статус и подпись доступа теперь используют контраст из D1 (`f69f7fe`); его проверка — 8/8 и бывший статус 2/2, контраст `#5b544a` на soft не ниже 5.16:1. D3 сохраняет подтверждения экранов, без дублирования этого общего правила.

Итог целевого прогона D3: первоначально 10/16 сценариев прошли; после исправления контраста повторены только шесть упавших сценариев — 6/6. После последнего изменения заголовка вход проверен вместе с axe на обеих ширинах — 4/4 (вход и выбранное действие исключения участника). Десктоп — 1/1. Полный `pnpm check` и общий визуальный прогон оставлены для согласованного окна перед отправкой.

Дополнительный узкий D3b прогон в Linux Playwright (`focus__title`): 360 и 412 px — 2/2, axe без блокирующих замечаний; в обоих случаях `font-weight: 500`, локальный Roboto загружен. Снимки после правки: [360 px](studio-focus-weight500-360.png) · [412 px](studio-focus-weight500-412.png). Использованы временная тестовая семья и отдельная PostgreSQL 18 в Docker-сети; контейнер удалён после прогона.
