Дополнительно каркас проверен на 1024 и 1600 px, на «Людях» и «Ещё»; 360/412 px — с axe.
Проверяется фактический фон внизу окна и отсутствие следов перехода после возврата из карточки.
Снимки для сравнения сняты с отключёнными анимациями, сохранены без изменения цветов при масштабе 1 px/px.

- [Карусель, 412 px, мобильная эмуляция и касание](carousel-412.webm).
- [Улёт, 412 px, мобильная эмуляция и касание](flight-412.webm).
- [Улёт, 1440 px, настольная раскладка](flight-1440.webm).

На каждой записи улёта: «Сегодня», «План», «Все дела»; галочка, свайп «Выполнено», свайп «В корзину».
Замеры по кадрам подтверждают 560 мс, непрозрачную копию в середине и попадание в фактическую цель в конце.
Карусель дополнительно проверена на 360/412 px в обоих режимах движения: сосед виден до отпускания,
вкладки и «+» не смещаются более чем на 1 px, нижнее меню сохраняет `aria-current` на «Сегодня».

Повторить: `pnpm --filter @homecrm/web test:e2e app app/feed-shell.e2e.ts app/feed-carousel.e2e.ts app/feed-flight.e2e.ts`.
На Windows снимки запускаются через отдельный Linux compose-проект `homecrm-test-d32`
с `apps/web/e2e/fullscreen-forms/compose.yaml`; исходный образ — `homecrm-test-d30:e2e-linux`.
