# D17 — действия во «Всех делах»

Все снимки получены в Chromium из Linux-контейнера Playwright 1.63.0 на вымышленной семье. Ширины: 360, 412 и 1280 px.

- `before-*.png`: исходный `origin/main` (`6037ddd`), после выполнения просроченного дела. Кружок пустой и недоступный, строка без зачёркивания, метка «Просрочено» остаётся, кнопок переноса нет.
- `after-*.png`: то же действие после D17. Строка остаётся в группе своей даты, название зачёркнуто, кружок заполнен галочкой; счётчик группы учитывает только открытые и ожидающие дела. У активных строк есть перенос.
- `history-child-*.png`: фильтр старых отменённых дел под ребёнком; строка зачёркнута, кружок не является кнопкой.

Причина исходного ненажимаемого кружка — условие `open/waiting` в `PlanRows`: для выполненного дела выводился обычный `span` с пустым кружком. Это воспроизводится на всех трёх ширинах; перекрытие элементов не было причиной.

Выполнение, возобновление и перенос используют общий `useFeedActions` и существующий `useTaskOperation`. Ошибки, конфликты версий, очередь офлайн и ограниченное окно отмены сохраняются. Старые завершённые дела скрываются по дате `updatedAt` в часовом поясе дома; их можно открыть фильтром статуса. Сервер и схема базы не менялись.

Из корня worktree:

```powershell
docker compose -f apps/web/e2e/all-tasks-actions/compose.yaml build playwright
docker compose -f apps/web/e2e/all-tasks-actions/compose.yaml run --rm playwright pnpm --filter @homecrm/web exec node e2e/run.ts app -c e2e/all-tasks-actions/playwright.config.ts --workers=1
docker compose -f apps/web/e2e/all-tasks-actions/compose.yaml run --rm playwright pnpm --filter @homecrm/web exec node e2e/run.ts app e2e/app/plan-studio2.e2e.ts --workers=1
docker compose -f apps/web/e2e/all-tasks-actions/compose.yaml down
```

Исходные снимки сняты до правок первым сценарием с `D17_BEFORE=1`; этот режим предназначен для исходного кода. Обычный запуск проверяет выполнение и отмену, возобновление, перенос и отмену, назначение дня, «Жду», повтор офлайн, доступ ребёнка и прямые отказы API. Граница суток проверяется в UTC+14: секунда до полуночи дома относится к предыдущему дню. Проверки axe, цели 44 px и отсутствие горизонтальной прокрутки — на всех трёх ширинах.

Настоящие телефоны и рабочее окружение этим прогоном не проверялись. Таблицу хода работ обновляет ведущий агент после приёмки PR.
