# R0.8c: проверка интерфейса сроков

Снимки сделаны Playwright в Linux-контейнере на вымышленной семье. Прогон
`e2e/app/deadlines.e2e.ts`: 16/16 сценариев на 360 и 412 px; axe, цели нажатия
от 44 px и отсутствие горизонтальной прокрутки проверяются вместе со снимками.
Дата API и браузера зафиксирована тестом; таймеры продолжают работать.
Сценарий доступа также проверяет смену аккаунта в открытой вкладке: свежий кэш
взрослого не переносит названия записей «Взрослые» в радар ребёнка.
