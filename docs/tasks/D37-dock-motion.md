- **Задача:** владелец 30 октября 2026 выбрал по живому примеру (https://claude.ai/artifact/A5SQiXYEQ1zAyx2UGCNTwB) четыре идеи для нижней панели «Сегодня · Дом · Док. · Люди · Ещё»: 1, 2, 4 и 8. Исполнитель — Codex (решение владельца).
- **Требования:** UI-8 (движение), UI-7 (доступность), стиль движения — сдержанный, как в iOS (решение владельца 25 октября 2026; токены `--ease-out`, `--ease-sheet` в `tokens.css`, система переходов D30 в `apps/web/src/shell/motion.tsx`).

- **Область:** `apps/web/src/shell/**`, `apps/web/src/styles/**` (кроме правил фокуса в `tokens.css` — их меняет D36), `apps/web/e2e/**`. **Не трогать:** сервер, базу, правила доступа, CI, `apps/web/src/tasks/**` (там работает D36), рабочее окружение `homecrm`.

## Что сделать

Длительности — как в примере после правки владельца («очень быстрые» — их замедлили).

1. **Плашка переезжает.** Светлая плашка активного раздела не перескакивает, а едет к нажатой кнопке: `transform` 420 мс, лёгкая пружина `cubic-bezier(0.34, 1.28, 0.52, 1)`. При первом показе и при переходе по ссылке/«Назад» плашка стоит на месте без анимации.
2. **Отклик на касание.** Пока палец на кнопке — иконка `scale(0.86)` (≈80 мс), отпустили — возврат 200 мс. Иконка активного раздела — залитая (вариант иконки Phosphor `weight="fill"`), неактивных — контурная; при выборе — короткий «пульс» `scale(1.1 → 1)` 320 мс.
4. **Повторное нажатие на активный раздел.** Если открыта вложенная страница раздела (карточка, форма) — вернуться к корню раздела; если корень прокручен — плавно наверх (`behavior: 'smooth'`); если уже наверху — ничего. Работает и при «уменьшить движение» (прокрутка без плавности).
8. **Экран вырастает из кнопки.** При переключении раздела новый экран проявляется (`opacity` 320 мс) и подрастает из точки над нажатой кнопкой: `transform-origin` — центр кнопки, `scale(0.88 → 1)` 450 мс `--ease-out`; старый уходит прозрачностью ~200 мс. Только при смене раздела нижней панелью; переходы внутри раздела (D30) и свайпы лент (D32) не меняются. Если используется View Transitions API — согласовать с `motion.tsx`, без двойной анимации.

- Только `transform` и `opacity`. `prefers-reduced-motion: reduce`: плашка и экран без движения (экран — короткая смена прозрачностью), пульса нет, повторное нажатие работает.
- Вибрации и собственных анимаций иконок (идеи 5, 6, 7) — нет.
- На широком экране (боковая панель вместо нижней) — то же поведение для плашки и повторного нажатия, если там есть аналог; иначе не трогать.
