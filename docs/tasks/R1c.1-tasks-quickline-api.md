# Бриф R1c.1–2. Дела, статус «жду» и разбор быстрой строки: база и API

- **Задача:** R1c.1 и R1c.2 из [плана](../03-dev-plan.md), серверная часть и общий разбор строки, одним PR. Экраны — отдельной задачей. Исполнитель — Codex.
- **Требования:** TASK-1, TASK-2, TASK-8; PRD 7.2, 7.3, разделы 12 и 13; [ADR-0028](../adr/0028-deadline-engine.md) (сроки), правила `packages/shared/src/access.ts`.
- **Ветка:** `feat/task-1-tasks`, в своём worktree от свежего `main`.

## Сделать

### R1c.1 Дело

1. **Модель** (TASK-1): дело — название, описание, пространство и аудитория, автор, исполнитель, дата плана или «без даты», точное время (необязательно), крайний срок, статус «открыто · сделано · отменено · не сделано · жду», отметка удаления. Даты без времени — отдельный тип, время — в часовом поясе дома, моменты — `timestamptz`. Поля повтора не делать (R1c.3), но схема не должна им мешать.
2. **Чек-лист, связи, файлы:** пункты чек-листа с порядком и отметкой; связи с объектом, контактом, документом, начислением — по образцу связей взаимодействий; файлы — через существующее хранилище. Скрытые связи не теряются при правке (как в R1b.4, пункт 7a).
3. **«Жду»** (TASK-8): от кого ждём (контакт или участник) и дата проверки; в эту дату — срок в движке сроков (источник `task_waiting`) и напоминание; в push — без текста, если включено «Скрывать текст на экране блокировки».
4. **API:** список с фильтрами (моё, назначил другим, без даты, жду, по объекту, по статусу), карточка, создание и правка с ключом идемпотентности, смена статуса (повторный запрос не создаёт двойных записей — задел под TASK-7), корзина и восстановление, история, перенос между пространствами, поиск, экспорт. Исполнитель должен видеть дело: если не видит — `409` с признаком расширения аудитории (подтверждение — в R1c.4, TASK-9).

### R1c.2 Быстрая строка

5. **Разбор** (TASK-2) — чистая функция в `packages/shared`, без ИИ и без запросов: даты «сегодня», «завтра», «послезавтра», «в пятницу», «15 октября», «15.10», «через неделю», «через 3 дня»; время «в 18:00», «в 9»; `@имя` — по списку участников; `#объект` — по списку объектов (передаются параметром). Результат — название без распознанных частей и список фрагментов с позициями, чтобы клиент показал их чипами и снял любой одним касанием.
6. **Тесты разбора:** набор из 100+ русских фраз в фикстуре (падежи, «пт», опечатки в пробелах, неоднозначные «в 5» и «15.10» в декабре → следующий год); текущая дата и часовой пояс — параметром.

### Для каждой новой сущности (AGENTS.md)

7. RLS ENABLE + FORCE, двойник в `access.ts`, строки матрицы, история, корзина, перенос, поиск, экспорт; в журналах нет названий и текстов дел; `redactUrl` знает новые маршруты.
