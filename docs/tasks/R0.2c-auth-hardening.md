## Сделать

1. **Лимит запросов** для маршрутов `list-sessions`, `revoke-session`, `revoke-other-sessions` (`apps/server/src/auth/routes.ts`): вернуть ограничение не мягче прежнего у Better Auth (120 в минуту на клиента); проверка источника запроса — тем же правилом, что у плагина (Origin/Referer и Fetch Metadata). Тест: превышение лимита даёт 429, чужой источник — отказ.
2. **Обёртка адаптера** (`apps/server/src/auth/auth.ts`): тест, который падает, если у адаптера Better Auth появился метод, не охваченный обёрткой хэширования; пункт в чек-листе обновления Better Auth (ADR-0005 или runbook). В ADR-0005 записать ограничение: строки, найденные не по токену, возвращаются с хэшем.
3. **Отзыв текущей сессии по id** стирает cookie в ответе, как обычный выход. Событие «сессия завершена с другого устройства» пишется в журнал входов (без токенов, без названий записей).
4. **`Cache-Control: no-store`** на всех ответах `/api` (успех и ошибки), статика не затрагивается. Тест на нескольких маршрутах, включая 401 и 404.
5. **Бэклог:** закрытые пункты вычеркнуть с пометкой «Закрыто R0.2c».
