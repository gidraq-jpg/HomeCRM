# Бриф R0.5e. Файлы: экраны

- **Задача:** загрузка и просмотр файлов в карточках заметок и объектов на готовом API (R0.5b, PR #20; [API файлов](../files-api.md), [ADR-0024](../adr/0024-files-storage-lifecycle.md)). Экраны заметок (R0.4b) и объектов (R0.5c) готовы — вкладка «Файлы» в карточке объекта сейчас пустая.
- **Требования:** OBJ-4, OBJ-1; PRD разделы 7.3, 13, 14; [ADR-0010](../adr/0010-files-encryption.md).
- **Ветка:** `feat/obj-4-files-ui`, в своём worktree от свежего `main`. Параллельно Codex меняет сервер (R0.5d) — туда не заходить.

## Сделать

1. **Вкладка «Файлы»** у объекта и раздел «Файлы» в карточке заметки: список (превью или значок PDF, имя, размер «2,4 МБ», дата «5 окт.», автор), пустое состояние.
2. **Загрузка:** «Добавить файл» — фото с камеры или из галереи и PDF; на телефоне фото уменьшается до 2560 px по длинной стороне перед отправкой (ADR-0010), предел 25 МБ проверяется до отправки с понятным текстом; прогресс, отмена, ошибки 413 и 415 — понятными словами. Несколько файлов — по очереди.
3. **Просмотр:** превью фото на экране, открытие полного файла и PDF; файл скачивается только через `/api/files/:id` с сессией. Ссылки «поделиться файлом» нет.
4. **Корзина:** «В корзину» с отменой 7 секунд; удалённые файлы — в карточке записи и в общей «Корзине», «Восстановить» по `access.ts`.
5. **Фото профиля** в «Обо мне»: загрузить и сменить (своё фото — `photoFileId`).
6. **Кэш и журналы:** ответы с файлами и превью не попадают в кэш сервис-воркера и Cache API, имена файлов — не в консоли, адресах, localStorage и названии вкладки; `blob:`-адреса освобождаются после показа.

## Готово, когда

Цели нажатия от 44 px, без горизонтальной прокрутки, без серьёзных замечаний axe. Скриншоты — в `docs/screenshots/R0.5e/` и в описании PR.
- Сквозной тест на вымышленной семье: файл объекта «Взрослые» не открывается ребёнку ни на экране, ни прямым запросом `/api/files/:id`.
- Тексты по PRD раздел 13; `pnpm check` и CI проходят.
- Чего не хватает в API — не менять сервер, записать в отчёте.
