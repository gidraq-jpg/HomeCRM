# Бриф R1a.7b–8b. Шаблоны, первый запуск, начисления и оплаты: экраны

- **Задача:** экраны R1a.7 и R1a.8 на готовом API (PR #41; [ADR-0034](../adr/0034-templates-charges.md), [контракт API](../templates-charges-api.md)), одним PR. Карточка недвижимости, «Счета», «Счётчики», «Показания», радар уже есть — расширять их, брать приёмы `apps/web/src/accounts`, `meters`, `deadlines`, `ui`.
- **Требования:** TPL-1…4, UTIL-9, UTIL-10, DEAD-4 («Отметить оплату»); PRD 7.2, разделы 13 и 14, приложения А и Б; сценарий S1.
- **Ветка:** `feat/tpl-1-templates-charges-ui`, в своём worktree от свежего `main`. Параллельно Codex делает R1a.9 + R1b.1 в `apps/server`, `packages/db`, `packages/shared` — туда не заходить. Сервер разработки — `PORT=8339`, `WEB_PORT=5201`.

## Сделать

1. **Первый запуск администратора** (TPL-1): мастер при пустом доме — дом, шаблон, первый объект, приглашения; каждый шаг можно пропустить, прогресс не теряется при перезагрузке (только в памяти и на сервере, не в localStorage).
2. **Применение шаблона** (TPL-2, TPL-3): из «Дома» («+» → «Из шаблона») и из пустых разделов (TPL-4). Список пунктов с галочками по группам (счета, счётчики с начальным показанием, организации, повторяющиеся сроки, налоговый режим для «Сдаваемой квартиры»), «Кто видит» над «Создать»; одно действие, повтор безопасен (ключ идемпотентности), ошибка — понятный текст, ничего не создано.
3. **Начисления** (UTIL-9): вкладка или раздел в счёте — период, строки по услугам, итог, срок оплаты, квитанция (файл), перерасчёт со знаком. Суммы вводятся в рублях с запятой («1 840,50»), хранятся и отправляются в копейках, без float.
4. **Оплаты** (UTIL-10): оплата к начислению — дата, сумма (по умолчанию остаток), кто заплатил, способ, чек; «Отменить оплату» с причиной вместо удаления, отменённая видна зачёркнутой с причиной. Статус начисления: «к оплате», «частично», «оплачено».
5. **Радар:** «Отметить оплату» на сроке начисления создаёт оплату на остаток (по контракту API), отмена — через отмену оплаты.
6. **Журналы и кэш:** ни сумм, ни номеров счетов, ни названий в консоли, адресах страниц, localStorage и кэше сервис-воркера.
