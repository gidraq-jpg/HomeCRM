# Бриф R0.4b. Заметки: экраны

- **Задача:** вторая половина R0.4 из [плана](../03-dev-plan.md) — экраны заметок на готовом API (R0.4a, [ADR-0020](../adr/0020-notes-api.md)). Каркас приложения готов (R0.3b, PR #15); прототип 0.5 проверен.
- **Требования:** NOTE-1…3 (без файлов, связей и тегов — их модули позже), SPACE-5…7, TPL-4; PRD разделы 7.3, 7.4, 13, 14.
- **Ветка:** `feat/note-1-notes-ui`, в своём worktree от свежего `main`. Параллельно Codex меняет `packages/db`, `access.ts` и сервер (R0.5a, `feat/obj-1-objects`) — туда не заходить.

## Сделать

1. **Раздел «Заметки»** в «Ещё» (по PRD, раздел 14): список под переключателем «Всё · Общее · Личное», закреплённые сверху, значок и подпись «Кто видит» у каждой, пустое состояние объясняет разницу личного и общего (TPL-4). Данные — только из API (`GET /api/notes`); вымышленных данных нет. Пример экрана — `apps/web/src/prototype/screens/Notes.tsx`: брать оформление, не данные.
2. **Карточка и правка:** заголовок (обязателен, до 200 символов), текст в Markdown (до 100 000; сырой HTML выключен, ссылки только `http`, `https`, `mailto`, `tel` — см. ADR-0020), чек-лист (до 200 пунктов, порядок, отметка), закрепление. Сохранение с `expectedUpdatedAt`: при конфликте — понятный текст и выбор «обновить» или «сохранить мою версию как копию».
3. **Создание** («+» → «Заметка»): строка «Кто видит» над «Сохранить» — значение по таблице PRD 7.2 и режиму переключателя (в «Личное» — личная, в «Общее» — общая, в «Всё» — личная). Ребёнку доступно «Только я» и «Вся семья».
4. **Действия по правилам 7.3 (SPACE-7):** «Поделиться…» (владелец личной), «Сделать личной…» (автор общей без чужого вклада; иначе — «Скопировать в личное»), «Кто видит…» (смена аудитории взрослым), «Скопировать в личное» (любой читатель). Недоступное действие не показывается; если оно недоступно из-за чужого вклада — короткое объяснение. Подтверждения: перенос в личное и сужение аудитории — экран «Кто потеряет доступ» из `POST /api/notes/:id/access-preview` и затем действие с `confirmed`.
5. **Корзина:** «В корзину» с отменой в течение 7 секунд (как в PRD для дел), раздел «Корзина» в «Ещё» со списком удалённых заметок, «Восстановить», срок хранения 30 дней; пустое состояние.
6. **Поиск:** NOTE-3 — полноценный поиск в R0.6; здесь только фильтр по заголовку в списке заметок на клиенте.
7. **Бэклог:** событие «Поделиться» остаётся в личном (бэклог «К R0.4b»): решить в интерфейсе — после «Поделиться» запись в общем пространстве показывает «Поделился(ась) автор, дата» из данных, которые отдаёт API; если API этого не отдаёт, **не менять сервер**, а записать в отчёте, что нужно. Закрытое вычеркнуть.
8. **Журналы и кэш:** ни заголовков, ни текстов заметок в консоли, адресах, localStorage и кэше сервис-воркера; ответы `/api` не кэшируются; черновик несохранённой заметки — только в памяти страницы.

- Тексты по PRD раздел 13; `pnpm check` и CI проходят.
