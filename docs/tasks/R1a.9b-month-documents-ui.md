# Бриф R1a.9b + R1b.1b. «Коммуналка за месяц», аналитика и документы: экраны

- **Задача:** экраны R1a.9 и R1b.1 на готовом API (PR #43; [ADR-0035](../adr/0035-month-documents-api.md), [контракт API](../month-documents-api.md)), одним PR. Брать приёмы `apps/web/src/accounts`, `charges`, `meters`, `deadlines`, `objects`, `ui`.
- **Требования:** UTIL-11, UTIL-12; DOC-1, DOC-2, DOC-5, DOC-6, DOC-7; PRD 7.2, разделы 12, 13 и 14, приложение Б.
- **Ветка:** `feat/util-11-month-documents-ui`, в своём worktree от свежего `main`. Параллельно Codex делает R1b.2–3 в `apps/server`, `packages/db`, `packages/shared` — туда не заходить. Сервер разработки — `PORT=8340`, `WEB_PORT=5202`.

## Сделать

1. **«Коммуналка за месяц»** (UTIL-11): экран из «Дома» — переключатель месяца, по каждому объекту и итогом: начислено, оплачено, к оплате; статус показаний по лицевым счетам (переданы, не переданы, окно ещё не открылось, не требуется) с переходом к «Показаниям» и «Начислениям». Пустой месяц — понятный текст и действие.
2. **Аналитика объекта** (UTIL-12): блок в карточке недвижимости — расход по ресурсам за 12 месяцев и суммы по месяцам, сравнение с тем же месяцем прошлого года. Простая доступная диаграмма (SVG без новых зависимостей) и таблица-дублёр для экранного диктора; расход — как пришёл строкой, без float.
3. **Документы** (DOC-1, DOC-2): раздел «Документы» (место в навигации — по PRD 14), карточка и форма: тип, владелец, серия и номер, кем выдан, дата выдачи, срок действия или «бессрочно», страницы-файлы, заметка, теги, ответственный за продление; «Кто видит» над «Сохранить», место по умолчанию — по PRD 7.2. Номер на экране скрыт до нажатия «Показать».
4. **Продление** (DOC-5): «Продлить» — форма новой версии; история версий, старая — «недействителен».
5. **Список и фильтры** (DOC-7): по человеку, типу, сроку («истекает в 90 дней», «просрочен») и пространству; поиск находит документ по названию и типу.
6. **Радар:** сроки документов с переходом в карточку; группа «Позже» уже есть — проверить вид.
7. **Журналы и кэш:** ни номеров, ни серий, ни сумм в консоли, адресах страниц, localStorage и кэше сервис-воркера.
