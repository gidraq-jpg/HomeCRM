# Бриф R1a.9 + R1b.1. «Коммуналка за месяц», аналитика и документы: база и API

- **Задача:** R1a.9 и R1b.1 из [плана](../03-dev-plan.md), серверная часть, одним PR (две задачи на бриф). Экраны — отдельной задачей на готовом API.
- **Требования:** UTIL-11, UTIL-12; DOC-1, DOC-2, DOC-5, DOC-6, DOC-7; PRD 7.2 (документы — где они по умолчанию и кто их видит), разделы 12 и 13; [ADR-0023](../adr/0023-objects-links-timeline.md), [ADR-0032](../adr/0032-meters-readings.md), [ADR-0034](../adr/0034-templates-charges.md), [ADR-0024](../adr/0024-files-storage-lifecycle.md) (файлы).
- **Ветка:** `feat/util-11-month-documents`, в своём worktree от свежего `main` — после слияния R1a.7–8.

## Сделать

### R1a.9 «Коммуналка за месяц» и аналитика

1. **`GET /api/utilities/month?month=YYYY-MM`** (UTIL-11): по каждому видимому объекту и итогом — начислено, оплачено, к оплате (копейки), статус показаний по лицевым счетам (переданы, не переданы, окно ещё не открылось, не требуется). Один запрос, без N+1; ребёнок не получает объекты «Взрослые» и их суммы.
2. **`GET /api/objects/:id/analytics`** (UTIL-12): расход по ресурсам за 12 месяцев (из показаний, с учётом замены счётчика и перехода через ноль), суммы начислений и оплат по месяцам, сравнение с тем же месяцем прошлого года. Расход — точные десятичные строки, деньги — копейки.

### R1b.1 Документы

3. **Документ** (DOC-1, DOC-2) — новая запись с полями доступа: тип из закрытого списка DOC-1 (данными в `packages/shared`), владелец (участник, контакт или объект — связь OBJ-2 или поле, решить в ADR), серия и номер, кем выдан, дата выдачи, срок действия или «бессрочно» (даты без времени), файлы (несколько страниц — R0.5), заметка, теги, ответственный за продление. Место по умолчанию — по PRD 7.2; паспорт и другие удостоверения ребёнка не видны другим детям.
4. **Версии** (DOC-5): «Продлить» — одна операция: новая версия документа, старая остаётся в истории со статусом «недействителен»; связи и ответственный переносятся.
5. **Список с фильтрами** (DOC-7): по человеку, типу, сроку («истекает в 90 дней», «просрочен») и пространству; поиск — по названию и типу; **номер документа в поисковый индекс не попадает** (раздел 12) — решение в ADR.
6. **Сроки документов** — источник `document` в движке сроков с предупреждениями по типу из приложения Б (паспорт РФ по возрасту — следующая задача R1b.2; здесь — только дата окончания).
7. **Для каждой новой сущности** (AGENTS.md): RLS ENABLE + FORCE, двойник в `access.ts`, строки матрицы, история, корзина и восстановление, перенос, экспорт; в журналах нет номеров, серий и названий.

## Готово, когда

- Тесты: месяц с частичной оплатой и перерасчётом; аналитика через замену счётчика и переход через ноль; ребёнок не видит сумм объекта «Взрослые»; документ: продление с версией, фильтры «истекает в 90 дней» и «просрочен» в часовом поясе дома, номер не находится поиском, срок появляется в радаре.
- Матрица доступа без расхождений; `GET /api/utilities/month` и `GET /api/deadlines` — по одному запросу и в пределах замера G4.
- Миграции безопасны для рабочей базы с данными v0.2.0 (после 0037); ADR (0035 или выше); `pnpm check` и CI проходят.
