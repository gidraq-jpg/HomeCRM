# Бриф D30. Понятный переход между экранами

- **Задача:** доработка UI-8 после проверки владельцем на телефоне — [ADR-0045](../adr/0045-motion-language.md), раздел «Уточнение 26 октября». Один PR, исполнитель — Codex. Можно параллельно с D29: области не пересекаются.
- **Требования:** UI-8, UI-1, раздел 13 PRD; [контракт Studio](../design/studio.md), раздел «Движение».
- **Ветка:** `fix/ui-8-screen-motion`, worktree `../HomeCRM-d30`, порты `PORT=8395`, `WEB_PORT=5257`.
- **Область:** `apps/web/src/shell/motion.tsx`, `apps/web/src/styles/motion.css`, `apps/web/src/styles/tokens.css` (только `--motion-screen`), `apps/web/src/shell/TopBar.tsx`, `apps/web/src/ui/FormHeading.tsx`, `apps/web/src/ui/StudioPage.tsx`, e2e движения, контракт Studio. **Не трогать:** листы, свайпы и строки дел (D28 их закрыл), сервер, базу, прототип 0.5.

## Что сделать

1. **«Назад» с движением.** Кнопки «Назад» в `TopBar`, `FormHeading`, `StudioPage` и ссылки `.back-link` — обратное движение (новый экран из −30 %, прежний уходит вправо). `navigate(-1)` обернуть в общий помощник из `motion.tsx`, без перевода роутера на data-режим. Системный «Назад» (браузер, жест Android) — попробовать через `popstate`/Navigation API в Chrome Android и Safari iOS; если ненадёжно или ломает фокус и прокрутку — оставить мгновенным и описать в отчёте.
2. **Глубина.** Входящий экран (`::view-transition-new(screen)` вперёд, прежний при «Назад») — фон панели Studio, скруглённые верхние углы как у панели, тень слева. Прежний экран — сдвиг на 30 % и `filter: brightness(.85)` к концу, обратное при «Назад».
3. **Шапка.** Если шапка у двух экранов разная (форма без верхней строки, карточка объекта со своим верхом) — проявление за `--motion-fast`; одинаковая — стоит на месте. Нижнее меню стоит всегда.
4. **Длительность:** `--motion-screen: 400ms`; других чисел не добавлять.
5. **«Уменьшить движение»** — как в D28: только затухание.

**Готово, когда:** вперёд и назад анимируются одинаково заметно; e2e на 360 и 412 px с axe: «список → карточка → Назад», «карточка → форма → Назад (шапка проявляется)», «вкладки — без сдвига», те же с `reducedMotion: 'reduce'`; к PR — короткая запись экрана вперёд/назад на 360 px и до/после; `pnpm check` и CI зелёные. Окончательная приёмка — владелец на телефоне после выпуска.

**Общие правила:** вымышленная семья; новых зависимостей не нужно; коммиты `UI-8: …`; PR открыть, не сливать; отчёт до 15 строк по шаблону `AGENTS.md`.
