## Сделать

1. **Фото профиля** в «Обо мне»: загрузить (с уменьшением, как у файлов), сменить, снять, вернуть снятое; фото в списке «Люди» и в карточке участника. Текст «Фото загружать пока нельзя…» убрать.
2. **Удалённые файлы:** в карточке заметки и объекта — «Удалённые файлы» из API (не только убранные в этом открытии), «Восстановить» по `canRestore`; в общем разделе «Корзина» — файлы рядом с заметками и объектами. Неверную подсказку после перезагрузки (`FilesSection.tsx:133, 317`) исправить.
3. **PDF на экране:** открытие через `/api/files/:id?inline=1`; скачивание остаётся.
4. **Доработки по ревью PR #21:** уменьшенный WebP не теряет прозрачность (или остаётся WebP); если уменьшенный файл больше оригинала — отправлять оригинал; `formatFileSize` для 1 048 000 Б — «1 МБ», а не «1024 КБ».
5. **Доработки по ревью PR #19** (бэклог): пустое состояние «Дома» согласовать с PRD 7.2 (машина, техника, «другое» — «Взрослые»), «Кто видит» пересчитывается при смене типа; ошибка «Восстановить» — текстом про восстановление; при `STALE_VERSION` события — выбор, как у заметок, а не молчаливая перезапись; отступ своих полей от строки «Изменён».
6. **Кэш и журналы:** как в R0.5e — ничего из файлов и имён в кэше сервис-воркера, адресах, localStorage, консоли.
