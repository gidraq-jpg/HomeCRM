# Бриф R0.5d. Объекты и файлы: доработки API по ревью

- **Задача:** закрыть замечания ревью и отчётов R0.5a–R0.5c из [бэклога](../backlog.md) на сервере — то, что мешает экранам или может подвести под нагрузкой.
- **Требования:** OBJ-1…4, SPACE-7; PRD разделы 7.3, 13; [ADR-0023](../adr/0023-objects-links-timeline.md), [ADR-0024](../adr/0024-files-storage-lifecycle.md), [API объектов](../objects-api.md), [API файлов](../files-api.md).
- **Ветка:** `fix/obj-1-api-review`, в своём worktree от свежего `main`. Параллельно Sonnet делает загрузку файлов на экранах (R0.5e, только `apps/web`) — туда не заходить. API файлов для экранов не менять несовместимо: добавлять можно, переименовывать и удалять поля нельзя.

## Сделать

1. **Связи** отдают у каждого видимого конца вид, название и признак «в корзине»; невидимый конец по-прежнему не отдаётся вовсе. Фильтр видимости — до LIMIT/OFFSET, чтобы страницы не были короче лимита (`links.ts:97`). Связь с концом в корзине не создаётся (409).
2. **Лента:** `updatedAt` ручных событий — ISO с `Z`, как у остальных ответов; список удалённых событий объекта для корзины (кто может восстановить — по `access.ts`); история полей, ушедших в корзину, в ленте не показывается.
3. **`PATCH /api/objects/:id`** снимает ответственного при `responsibleId: null`.
4. **Каскад событий** (0014) — без UPDATE по всей таблице `object_events`: только строки этого объекта. `record_guard` (0009:89) — «по умолчанию закрыто»: таблица, не внесённая в список, — ошибка при миграции или тест, который ловит её.
5. **Экспорт объектов** (`GET /api/objects/export`, `exportLinks`) — постранично, без запроса на каждую строку.
6. **Файлы:**
   - загрузка: сначала принять и подготовить файл (тип, превью, шифрование), потом короткая транзакция с `FOR UPDATE` родителя (`files/routes.ts:85-99`);
   - `createDecipheriv` с `authTagLength: 16` (`files/crypto.ts:20`);
   - компенсация после COMMIT не стирает блоки живой строки, если ответ не дошёл до клиента (`files/service.ts:30-34`);
   - `failOn` в sharp — не отклонять обычные фото с мелкими дефектами JPEG (`files/media.ts:60`), тест на таком файле;
   - сохранять ICC-профиль при удалении остальных метаданных (`files/media.ts:63`);
   - сообщение при ошибке настройки не говорит про ключ файлов, если дело не в нём (`main.ts:173-177`);
   - `Promise.all` на одном соединении в `household/routes.ts:107` — последовательно.
7. **Бэклог:** закрытые пункты вычеркнуть с пометкой «Закрыто R0.5d».
