# Бриф R0.7b. Уведомления: экраны и push на телефоне

- **Задача:** экраны уведомлений на готовом API R0.7 (PR #28, [ADR-0029](../adr/0029-notification-dispatcher.md), [ADR-0009](../adr/0009-web-push.md)) и приём push в сервис-воркере.
- **Требования:** NOTIF-1 (помочь установить PWA и разрешить уведомления), NOTIF-4, NOTIF-6, NOTIF-7 (журнал — в настройках); PRD разделы 13, 14.
- **Ветка:** `feat/notif-1-push-ui`, в своём worktree от свежего `main`. Параллельно Codex меняет `apps/server/src/deadlines`, `apps/server/src/notifications` и `apps/web/src/deadlines` (R0.8c) — туда не заходить.

## Сделать

1. **Разрешение и подписка:** после входа — ненавязчивая карточка на «Сегодня»: установить приложение на телефон (если не установлено) и включить уведомления; отказ запоминается, карточка не мешает. Подписка: `GET /api/push/key` → `pushManager.subscribe` → `POST /api/push/subscriptions` с понятным названием устройства («Android · Chrome»). Если браузер не умеет push или разрешение отклонено — объяснение, как включить в настройках браузера.
2. **«Ещё» → «Уведомления»:** включить на этом устройстве; список своих устройств с отключением (`GET`, `DELETE /api/push/subscriptions`); тихие часы, дневной бюджет, виды уведомлений, «Скрывать текст на экране блокировки» (`GET`, `PATCH /api/notifications/settings`); «Журнал доставки» — отдельный экран из настроек (`GET /api/notifications/deliveries`): когда, вид, устройство, итог — без названий записей, если их нет в ответе.
3. **Сервис-воркер** (`apps/web/src/pwa/sw.ts`): событие `push` показывает уведомление (заголовок и текст из содержимого или «В HomeCRM есть новое»; значок приложения; `tag` по записи, чтобы не копились одинаковые); `notificationclick` открывает или фокусирует приложение на карточке записи; `pushsubscriptionchange` переподписывает. Содержимое push не попадает в кэш, консоль и хранилище.
4. **Тексты** — по PRD раздел 13: формы множественного числа, время «22:00–8:00» в часовом поясе дома.

## Готово, когда

- Playwright на 360, 412 и 1280 px с axe: карточка на «Сегодня», экран «Уведомления», журнал, отказ в разрешении, браузер без push. Подписку и `push` в сервис-воркере проверить с подменой `PushManager` и событием `push` в тесте. Цели нажатия от 44 px, без горизонтальной прокрутки. Скриншоты — в `docs/screenshots/R0.7b/` и в описании PR.
- Сквозной тест на вымышленной семье: участник видит и отключает только свои устройства и свой журнал.
- В отчёте — пошаговая проверка для владельца на Android по Wi-Fi и мобильной сети (выполнится после выпуска v0.2.0).
- `pnpm check` и CI проходят. Чего не хватает в API — сервер не менять, записать в отчёте.
