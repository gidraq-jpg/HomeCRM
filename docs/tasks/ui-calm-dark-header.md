Проверить связность верхней области, включая ссылки возврата перед шапкой, без случайных светлых/тёмных полос.

Проверить общие компоненты и специализированные переопределения, а не только .btn.
- Круги внутри пиктограмм, аватары, точки, галочки/радио/переключатели сохраняют предметную семантику; не применять blanket border-radius ко всем элементам без разбора.
