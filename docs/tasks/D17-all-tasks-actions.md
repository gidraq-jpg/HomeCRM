2. **По умолчанию — только открытые и ожидающие.** Список без выбранного статуса совпадает с числом в шапке. Выполненные и отменённые — только через фильтр «Статус дел», отдельной группой «Выполнено» / «Отменено» в конце, а не в группах по дате (не в «Просрочено»).
