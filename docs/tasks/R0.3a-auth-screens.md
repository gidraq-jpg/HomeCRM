# Бриф R0.3a. Экраны входа и основа PWA

- **Задача:** R0.3a — экраны к готовому API R0.2 и установка оболочки приложения на телефон.
- **Требования:** AUTH-1…9, PRD, раздел 14 (состояния), строка «К R0.3» в `docs/backlog.md`.
- **Ветка:** `feat/auth-1-screens`, отдельный worktree `../HomeCRM-auth-screens` от свежего `main`.

## Сделать

1. Экраны входа в `apps/web`: вход по имени или почте, код второго фактора, «доверять устройству» (кроме администратора), резервные коды, сброс пароля по ссылке, сообщение о блокировке. API — `apps/server/src/auth`, бриф прошлой задачи — `docs/tasks/R0.2-auth.md`.
2. Установка на телефон: manifest, значки, сервис-воркер только для оболочки; данные не кэшировать.
3. Плашка «Без сети»; загрузка и ошибка у каждого блока.
4. Playwright с axe в CI (`.github/workflows`), ширины 360 и 412 px.

## Не трогать

Нижнее меню, переключатель пространств и «Кто видит» ждут проверки прототипа владельцем. Не менять `packages/db`, `packages/shared/src/access.ts` и сервер, кроме мелких правок, без которых экран не работает; такие правки объяснить в отчёте.

Рабочее окружение, compose-проект `homecrm`, порты 8300, 8301, 8309 и чужие контейнеры не трогать.
