# DOC-7, CONT-1…2, UI-3/8. Компактные фильтры на тестовом стенде

Команда владельца от 4 ноября 2026: реализовать предложенный вариант на тестовой базе для просмотра. База — локальный 7f07ffb, текущие ветка и worktree. Только локальная реализация и коммит; без push, PR, merge и выпуска.

## Результат

- Документы: поиск и кнопка «Фильтры» в одной строке; быстрый выбор «Все / Истекают / Просрочены». «Истекают» означает ближайшие 90 дней, это явно объясняется доступной подписью. «Все» сбрасывает только срок, по умолчанию показываются действующие версии.
- Человек, тип, срок и версии доступны в существующем нижнем Sheet. Черновые условия применяются только кнопкой «Применить»; крестик, Escape, системный возврат и жест закрытия отменяют черновик. Повторное открытие начинает с применённых условий. Внутри панели есть сброс черновика.
- Над результатами компактно видны только применённые недефолтные условия с возможностью снять условие и общий «Сбросить». Счётчик на кнопке отражает число недефолтных групп, включая срок и версии, но не текст поиска и не глобальное пространство. Общий сброс возвращает все локальные фильтры, включая версии и поиск, к исходным значениям.
- Люди: две доступные локальные вкладки «Контакты / Участники дома», контакты по умолчанию. В личном пространстве только контакты. Приглашение, бывшие участники, роли и карточки остаются доступны на вкладке участников согласно прежним правам.
- Контакты: строка поиска с «Фильтры», все прежние категории и организации в нижней панели; черновик/применение/отмена как у документов. Над списком только выбранная категория с удалением. Импорт, добавление человека/организации, пустые состояния и пагинация сохраняются. Убрать дублирующее добавление человека, если оно осталось в шапке и секции одновременно, сохранив доступность действия.
- Поиск применяется сразу с прежним debounce/deferred поведением. Переключение вкладок не сбрасывает поиск и применённые фильтры контактов. Смена пространства сохраняет действующие границы доступа и не оставляет невидимую вкладку участников.
