# Бриф D41. ИИ через чат: коннектор MCP для Claude и ChatGPT

- **Задача:** владелец 1 ноября 2026: «MCP и отдельный профиль для ИИ: добавление дел, объектов, заметок через чат с ИИ; возможность переноса в личку». Решения владельца: ключ у каждого участника (не отдельный профиль ИИ), всё — черновиками во «Входящие», ИИ читает только для привязки, только создание, подключать могут все участники. Исполнитель — Codex. **Запускать после слияния D39 и D40.**
- **Требования:** CHAT-1…7 (PRD 16.3), AI-2…5, INBOX-3…5, AUTH-6…8, SPACE-4, SPACE-7, раздел 13.
- **Ветка:** `feat/chat-1-mcp`, worktree `../HomeCRM-d41`, порты `PORT=8460`, `WEB_PORT=5320`, compose-проект `homecrm-test-feat-chat-1-mcp`.
- **Область:** `apps/server/src/**` (новый модуль `mcp/` и `oauth/`, «Входящие»), `packages/db` (миграции, RLS, матрица доступа), `packages/shared` (схемы), `apps/web/src/**` (согласие, профиль, «Входящие»), `deploy/**` (только маршрут туннеля, без выпуска), `docs/adr/`, e2e.
- **Не трогать:** рабочее окружение `homecrm`, VPS и DNS (CHAT-1 в рабочем окружении включает владелец), шлюз ИИ R2 (ADR-0043) — этот путь его не использует.

## Сначала — ADR (отдельный коммит, до кода)

`docs/adr/0048-chat-mcp.md`: удалённый MCP-сервер по Streamable HTTP на том же адресе через туннель (`/mcp`); OAuth 2.1 с PKCE и динамической регистрацией клиентов, как требуют коннекторы Claude и ChatGPT (проверить их текущую документацию и записать ссылки); формат и хранение ключей (только хэш), сроки, отзыв; почему без отдельного профиля ИИ; что уходит наружу (CHAT-3) и защита от внедрения инструкций (ИИ не может ничего сохранить сам). Новые зависимости (например, официальный `@modelcontextprotocol/sdk`) — с обоснованием в ADR.

## Сделать

1. **OAuth-сервер HomeCRM:** метаданные авторизации, регистрация клиента, страница входа (существующий вход: пароль, второй фактор, пределы попыток AUTH-8), экран согласия на русском («Claude просит: создавать черновики во „Входящих“, видеть названия ваших объектов и имена людей»), выдача и обновление ключа. Ключи хранятся хэшем; привязаны к участнику; CHAT-5 — отзыв, 90 дней без использования, отзыв при смене пароля и «Выйти на всех устройствах».
2. **MCP-сервер, инструменты:**
   - `find_objects`, `find_people`, `list_meters(object)` — только названия и идентификаторы видимого участнику (через те же правила `access.ts` и RLS, роль участника, никаких обходов);
   - `create_drafts(items[])` — один вызов, несколько черновиков: дело (название, срок в часовом поясе дома, ответственный, объект), заметка, покупка, объект, контакт, показание (счётчик, значение — точное, как в ADR-0032). Входы проверяются zod; неуверенные поля передаются отметкой.
   - Описания инструментов — понятные модели, по-русски и по-английски; ответы — короткие («Добавлено во „Входящие“: 3 черновика»).
3. **«Входящие»:** элемент с источником «чат ИИ» и меткой «от ИИ»; подтверждение пачкой («Сохранить выбранные»); при подтверждении — выбор пространства и аудитории, по умолчанию личное (CHAT-2). Элементы видит только автор (INBOX-5).
4. **Профиль:** ключи ИИ среди устройств с «Отключить»; журнал действий ИИ без текстов (CHAT-6). Настройка дома «ИИ через чат» у администратора (CHAT-7).
5. **Пределы:** число запросов на ключ в минуту и в сутки; превышение — понятная ошибка инструмента.
6. **Доступ:** новая сущность ключей и журнала — с полями доступа, политикой RLS, строками матрицы доступа, решением о поиске (не ищется), экспорте (журнал — да, ключи — нет) и корзине (ключи не в корзину, удаляются при отзыве).
7. **Журналы сервера** — без текстов запросов, черновиков, названий объектов (раздел 13, AI-5).
8. **Инструкция** `docs/runbook-chat-ai.md` для владельца: как подключить в Claude (веб и телефон) и ChatGPT по шагам, как отключить.

**Готово, когда:**
- Интеграционные тесты: полный путь OAuth (регистрация → вход → согласие → ключ → MCP-вызов); ключ ребёнка не видит объекты «Взрослые»; ключ участника не видит чужое личное (матрица доступа); `create_drafts` создаёт только элементы «Входящих» автора; отозванный и просроченный ключ отклоняются; смена пароля отзывает ключи; превышение предела; выключенная настройка дома.
