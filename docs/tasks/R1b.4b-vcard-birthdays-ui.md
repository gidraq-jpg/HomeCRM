# Бриф R1b.4b–5b. Импорт vCard, дни рождения и долги клиента: экраны

- **Задача:** экраны R1b.4 и R1b.5 на готовом API (PR #47; [ADR-0037](../adr/0037-vcard-birthdays-api.md), [контракт API](../vcard-birthdays-api.md)), одним PR; плюс клиентские долги из [бэклога](../backlog.md), которые закрывает новое API. Исполнитель — Codex (с 10 октября вся работа у Codex).
- **Требования:** CONT-6, CONT-7; PRD 7.2, разделы 13 и 14. Брать приёмы `apps/web/src/people`, `documents`, `deadlines`, `charges`, `ui`.
- **Ветка:** `feat/cont-6-vcard-birthdays-ui`, в своём worktree от свежего `main`. Сервер разработки — `PORT=8342`, `WEB_PORT=5204`.

## Сделать

1. **Импорт vCard** (CONT-6): в «Людях» — «Импорт из файла»: выбор `.vcf`, предпросмотр (новые и совпадения по телефону), для совпадений — «Объединить» или «Создать отдельно», «Кто видит» над «Импортировать», одно действие с ключом идемпотентности; итог — «Добавлено 3 контакта, объединено 1» (формы множественного числа); битый файл — понятный текст.
2. **Дни рождения** (CONT-7): переключатель «Напоминать о дне рождения» в карточке человека и в «Обо мне»; срок в радаре и на «Сегодня» с переходом в карточку; без года — без возраста, с годом — «исполнится 40».
3. **Долги клиента:**
   - радар: «осталось 1 840,50 ₽» у начисления; «Отменить» после «Отметить оплату» — по `paymentId` из ответа вместо слепка (`deadlines/markPayment.ts` можно упростить);
   - начисление и оплата — с ключом идемпотентности;
   - «Коммуналка за месяц» — переключатель «Всё · Общее · Личное» по месту объекта;
   - документы — названия объекта и контакта-владельца, файлы из карточки без отдельного запроса;
   - паспорт — подпись «20 лет» или «45 лет» из `expiryRule`, без эвристики по дате выдачи;
   - лента объекта — название контакта из API, без запроса на каждую запись;
   - контакты в глобальном поиске; корзина для людей и взаимодействий;
   - форма взаимодействия и человека не отправляет скрытые связи (сервер их сохраняет — проверить e2e).
4. **Журналы и кэш:** ни ФИО, ни телефонов, ни дат рождения, ни содержимого файла vCard в консоли, адресах, localStorage и кэше сервис-воркера; файл не кэшируется.
