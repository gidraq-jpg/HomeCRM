## Приёмка

- «Добрый день,» и имя вошедшего участника крупно, в два блока. Имя из доступного существующего профиля; безопасный fallback к имени учётной записи.
- Строка даты — настоящая дата в часовом поясе дома.
- Три показателя: доступные дела сегодня, близкие сроки, объекты. Использовать текущие запросы/нормализацию/фильтры.
Определения, временное окно и неполные/загружаемые данные описать в контракте. Числа не хардкодить и не показывать 0 вместо ошибки/загрузки.
Не добавлять API endpoint ради счётчика; если точное число недоступно, сообщить лидy и предложить честное отображение.
- Нажатие показателей открывает текущие ленты/радар/«Дом» с действующим пространством.
- В светлой панели остаются главное дело, быстрая строка, ленты «Сегодня/План/Все дела», показания, срочное из радара, выполненное,
карточки первого запуска/push и существующие сообщения ошибок/офлайна. Их состояния и действия не теряются.
- SPACE-5/6: выбранное пространство применяется к спискам и показателям; личное помечается; контекст и аудитории не упрощаются.
- Никаких новых продуктовых возможностей и изменений конфликтов, оплаты, сохранения и передачи дел.
- Длинные имена и заголовки, отсутствие дел, ошибка блока и увеличение текста 200% не ломают вёрстку.
- Главное действие доступно над нижним меню либо при нормальной прокрутке с правильным нижним запасом.
