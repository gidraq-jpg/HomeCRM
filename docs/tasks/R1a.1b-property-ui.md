# Бриф R1a.1b–3b. Недвижимость, организации, лицевые счета: экраны

- **Задача:** экраны R1a.1–R1a.3 на готовом API (PR #34; [ADR-0031](../adr/0031-property-accounts.md), [контракт API](../property-accounts-api.md)). Объекты, карточка с вкладками, связи и корзина уже есть (R0.5c) — расширять их, брать приёмы `apps/web/src/objects`, `notes`, `ui`. Цель этапа — к окну показаний 20–25 ноября семья заводит квартиру с лицевыми счетами.
- **Требования:** UTIL-1, UTIL-2, CONT-2, CONT-3, OBJ-5; PRD 7.2, раздел 14 («Карточка объекта»), сценарий S1, разделы 12 и 13, приложение А.
- **Ветка:** `feat/util-1-property-ui`, в своём worktree от свежего `main`. Параллельно Codex делает R1a.4–5 в `apps/server`, `packages/db`, `packages/shared` — туда не заходить. Сервер разработки — `PORT=8333`, `WEB_PORT=5195`.

## Сделать

1. **Недвижимость в «Обзоре» и при создании:** вид, адрес, площадь (ввод «54,3», хранение целыми сотыми м²), кадастровый номер с подсказкой формата, статус («живём», «сдаётся», «пустует»), собственники — участники дома. Статус — рядом с названием в «Доме» и в заголовке карточки. Ошибки формата — у поля, по-русски.
2. **Вкладка «Счета»** в карточке недвижимости: список лицевых счетов (поставщик, услуги, номер, способ передачи и окно «с 20 по 25»), создание и правка — поставщик из организаций (и «+ Новая организация» прямо из формы), услуги из закрытого списка, способ передачи со ссылкой, окно, день оплаты, кто платит, ссылка на личный кабинет, заметка. Скрытый поставщик (API отдаёт `null`) — «Поставщик скрыт» без названия; форма не стирает его при сохранении других полей. Корзина с отменой 7 секунд.
3. **Организации:** «Ещё → Организации» — список с фильтром по типу, карточка (телефоны с подписью и меткой «аварийный» — номер виден и копируется, звонок по ссылке `tel:`), сайт, адрес, часы, заметка; создание, правка, корзина. По умолчанию — общее, «Вся семья».
4. **«Люди и организации»** в «Обзоре» объекта: блок из API (связь с подписью роли — «УК», «поставщик»…), «Связать…» с выбором организации, удаление связи.
5. **Корзина:** лицевые счета и организации — в общем разделе «Корзина»; счёт восстанавливается вместе с объектом.
6. **Журналы и кэш:** ни названий, ни номеров счетов, ни адресов в консоли, адресах страниц, localStorage и кэше сервис-воркера.
