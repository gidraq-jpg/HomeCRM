# Вымышленные PDF для D33 / AI-9

Все данные вымышленные. Генерация из корня:
`node apps/server/src/ai/eval/generate-pdfs.ts`.
Нужны dev-зависимости и установленный клиентский Onest; PDF сохраняются в эту папку.
Текстовые образцы содержат встраиваемые подмножества кириллицы и латиницы Onest.
Сканы генерируются sharp из SVG с теми же строками; шрифт растра зависит от системы.
Существующие файлы нужны тестам, в CI их не следует перегенерировать.

- `receipt-text.pdf`, `receipt-scan.pdf` — квитанция ЖКХ: лицевой счёт 9900000010,
  период 2026-09, сумма ровно 123456 копеек, оплатить до 2026-10-25.
- `mixed.pdf` — та же квитанция, текст и скан в одном PDF.
- `contract.pdf` — договор на восемь страниц; проверяются первые пять.
- `encrypted.pdf` — пустой PDF с настоящим шифрованием Standard R2, учебный пароль `test`.
- `broken.pdf` — намеренно повреждённый файл с сигнатурой PDF.
- `identity.pdf`, `identity-scan.pdf` — недействительный учебный макет паспорта.

Оценка: `pnpm ai:eval --kind=pdf`. По умолчанию fake (`mode: contract`):
это проверка протокола, а не OCR/качества. Для известных сканов fake использует
хеши нормализованных растров. Оценка Hermes с `AI_EXTRACT_PROVIDER=openai-compatible`
использует реальные ответы модели; пороги — ≥85% полей квитанции, точная сумма,
100% личности. Отчёт печатает только агрегаты по полям и время.
