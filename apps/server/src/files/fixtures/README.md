# Тестовое фото HEIC

`pattern.heic` — созданная для теста одноцветная картинка 16×16, без людей и пользовательских данных. Исходный PNG создан sharp (цвет `#44aa88`), HEIC — `heif-enc -q 90` из libheif-examples в одноразовом официальном Debian bookworm-slim. Метаданных пользователя нет. Тест проверяет фактическое HEVC-декодирование, а не только сигнатуру.
