## Дополнительно для Claude Code

- Оболочка на компьютере владельца — PowerShell 7; команды из `AGENTS.md` работают в ней без изменений.
- Исполнитель работает в отдельном worktree: в приложении Claude — новая сессия с worktree; в терминале — `git worktree add ../HomeCRM-<ветка> -b <ветка>`, затем `claude` в этой папке. Одна сессия — одна задача; после отчёта сессия закрывается.
- Перед коммитом — `pnpm check`. В конце сообщения коммита — строка `Co-Authored-By: Claude <noreply@anthropic.com>`.
- Владельцу и ведущему отвечайте по-русски, в формате отчёта из `AGENTS.md`: до 15 строк.
